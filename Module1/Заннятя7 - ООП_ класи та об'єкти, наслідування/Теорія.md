# 📘 УРОК: ООП — класи, об’єкти, наслідування

## 🔹 1. Що таке ООП

**ООП (Object-Oriented Programming)** — це стиль програмування, де ми працюємо не просто з функціями, а з **об’єктами**.

👉 Об’єкт = дані + поведінка

Приклад з життя:

* 🚗 Авто

  * дані: колір, швидкість
  * дії: їхати, гальмувати

---

## 🔹 2. Клас і об’єкт

### 📌 Клас — це шаблон (як креслення)

### 📌 Об’єкт — це конкретний екземпляр

---

### ✅ Приклад (Python)

```python
class Car:
    def __init__(self, brand, speed):
        self.brand = brand
        self.speed = speed

    def drive(self):
        print(f"{self.brand} їде зі швидкістю {self.speed} км/год")
```

---

### 🔹 Створення об’єкта

```python
car1 = Car("BMW", 120)
car2 = Car("Audi", 100)

car1.drive()
car2.drive()
```

---

## 🔹 3. Властивості і методи

* **Властивості (properties)** → змінні в класі
* **Методи (methods)** → функції в класі

```python
class User:
    def __init__(self, name):
        self.name = name  # властивість

    def say_hello(self):  # метод
        print(f"Привіт, я {self.name}")
```

---

## 🔹 4. Інкапсуляція (база)

👉 Ідея: **ховати внутрішню логіку**

```python
class BankAccount:
    def __init__(self, balance):
        self._balance = balance  # "protected"

    def deposit(self, amount):
        self._balance += amount

    def get_balance(self):
        return self._balance
```

---

## 🔹 5. Наслідування (Inheritance)

👉 Дозволяє створювати нові класи на основі існуючих

---

### ✅ Приклад

```python
class Animal:
    def speak(self):
        print("Я тварина")

class Dog(Animal):
    def speak(self):
        print("Гав")
```

---

### 🔹 Використання

```python
dog = Dog()
dog.speak()  # Гав
```

---

## 🔹 6. Виклик батьківського класу (super)

```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)
        self.breed = breed
```

---

## 🔹 7. Поліморфізм (бонус 🔥)

👉 Один метод — різна поведінка

```python
class Cat:
    def speak(self):
        print("Мяу")

class Dog:
    def speak(self):
        print("Гав")

animals = [Cat(), Dog()]

for animal in animals:
    animal.speak()
```
