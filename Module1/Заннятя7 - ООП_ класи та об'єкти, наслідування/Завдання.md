# 🔴 Рівень 4 — майже реальна задача

## ✅ Завдання 7: Інтернет-магазин

Створи:

### 1. Клас:

```
Product
```

* name
* price

---

### 2. Клас:

```
Cart
```

### Поля:

* products (список)

### Методи:

* add_product(product)
* total_price()

---

👉 Приклад:

```python
cart.add_product(Product("Phone", 500))
cart.add_product(Product("Laptop", 1000))

print(cart.total_price())  # 1500
```
