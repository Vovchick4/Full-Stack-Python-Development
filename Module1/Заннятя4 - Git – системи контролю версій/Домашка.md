### 🏁 Домашнє завдання: «Мій перший крок у світі Open Source»

#### Частина 1: Підготовка (якщо ще не зроблено)

1. **Встанови Git** на свій комп'ютер (якщо Windows — використовуй Git Bash).
2. **Налаштуй себе:** введи в терміналі своє ім'я та email через `git config --global`.
3. **Створи SSH-ключ** та додай його у свій профіль на GitHub (Settings -> SSH keys).

#### Частина 2: Робота з локальним репозиторієм

1. Створи на комп'ютері нову папку з назвою `git-practice`.
2. Зайди в неї через термінал (`cd git-practice`).
3. Ініціалізуй репозиторій командою `git init`.
4. Створи файл `README.md` (можна просто вручну або командою `touch README.md`).
5. Відкрий цей файл у блокноті чи VS Code і напиши: *«Це мій перший репозиторій. Я вчуся працювати з Git!»*.
6. Додай файл до "черги" на збереження: `git add README.md`.
7. Зроби свій перший коміт: `git commit -m "Перший запис у README"`.

#### Частина 3: Робота з GitHub

1. Зайди на свій GitHub і створи новий репозиторій (кнопка **New**). Назви його так само: `git-practice`. **Не** став галочку "Add a README file" (бо ми його вже створили локально).
2. GitHub покаже тобі підказку «…or push an existing repository from the command line». Скопіюй звідти ці три команди (вони виглядають приблизно так):
* `git remote add origin git@github.com:ТВІЙ_НІК/git-practice.git` (підключення до хмари).
* `git branch -M main` (називаємо головну гілку "main").
* `git push -u origin main` (відправляємо код у хмару).



#### Частина 4: Перевірка

1. Онови сторінку свого репозиторію на GitHub. Якщо ти бачиш там свій файл `README.md` з текстом — **вітання, ти це зробив!**


`git status` -> `git add .` -> `git commit -m "Оновив текст"` -> `git push`.

**Як виконаєш — пиши, і ми розберемо, як виправляти помилки, якщо ти випадково видалив щось зайве!** 🚀
