# 🔥 ЗАДАЧА 4: Inventory (реальний кейс)

## 🧠 Умова

Є склад:

---

## ✅ Завдання:

```python
class Inventory:
    def __init__(self):
        self.products = {}

    def add(self, product, qty):
        if product.name not in self.products:
            self.products[product.name] = 0
        self.products[product.name] += qty

    def remove(self, product, qty):
        if self.products.get(product.name, 0) < qty:
            raise Exception("Not enough stock")
        self.products[product.name] -= qty
```

        return 0

---

## 💥 Завдання:

👉 Інтегруй це в Order:

```python
class Order:
    def __init__(self, cart, payment, delivery):
        self.cart = cart
        self.payment = payment
        self.delivery = delivery

    def checkout(self):
        amount = self.cart.total()
        delivery_cost = self.delivery.calculate(amount)
        total = amount + delivery_cost
        return self.payment.pay(total)
```

# 📘 ДОПОВНЕННЯ: 4-й принцип ООП — Абстракція

## 🧠 Що це таке

👉 Абстракція — це коли ти:

* показуєш **тільки потрібний інтерфейс**
* ховаєш **деталі реалізації**

📌 Простими словами:
**ти знаєш “що робити”, але не знаєш “як саме всередині”**

---

## 🔥 В Python це робиться через `abc`

```python
from abc import ABC, abstractmethod
```

---

# ✅ БАЗОВИЙ ПРИКЛАД

```python
from abc import ABC, abstractmethod

class Payment(ABC):

    @abstractmethod
    def pay(self, amount):
        pass
```

---

## ❗ Важливо

```python
p = Payment()  # ❌ ПОМИЛКА
```

👉 Не можна створити абстрактний клас напряму

---

# ✅ Реалізація

```python
class CardPayment(Payment):
    def pay(self, amount):
        return f"Оплата {amount} картою"

class CryptoPayment(Payment):
    def pay(self, amount):
        return f"Оплата {amount} криптою"
```

---

# 🔥 Чому це важливо (реальний сенс)

У тебе є код:

```python
def process(payment: Payment):
    print(payment.pay(100))
```

👉 І тобі **все одно**, що передадуть:

```python
process(CardPayment())
process(CryptoPayment())
```

---

# 💥 Це і є АБСТРАКЦІЯ:

* ти працюєш через **інтерфейс**
* а не через конкретну реалізацію

---

# ⚡ ВАЖЛИВА ФІШКА (часто питають на співбесіді)

## 👉 Абстрактний клас може мати звичайні методи

```python
class Payment(ABC):

    def validate(self, amount):
        if amount <= 0:
            raise ValueError("Invalid amount")

    @abstractmethod
    def pay(self, amount):
        pass
```

---

## Використання:

```python
class CardPayment(Payment):
    def pay(self, amount):
        self.validate(amount)
        return f"Оплата {amount}"
```

# 🔥 ПРАКТИКА (додай до уроку)

## 🧠 Задача: Shape (класика інтерв’ю)

---

## ✅ Завдання:

Створи абстрактний клас:

```python
class Shape(ABC):
    @abstractmethod
    def area(self):
        pass
```

---

## Реалізація:

```python
class Rectangle(Shape):
    def __init__(self, w, h):
        self.w = w
        self.h = h

    def area(self):
        return self.w * self.h


class Circle(Shape):
    def __init__(self, r):
        self.r = r

    def area(self):
        return 3.14 * self.r ** 2
```

---

## Використання:

```python
shapes = [Rectangle(2, 3), Circle(1)]

for s in shapes:
    print(s.area())
```
