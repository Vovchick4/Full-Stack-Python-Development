## 1. Що таке FastAPI та чому він крутий?
FastAPI побудований на базі двох потужних бібліотек:
* **Pydantic** — для валідації даних.
* **Starlette** — для веб-частини.

Його головні переваги: **швидкість** (співставна з NodeJS та Go), автоматична документація (Swagger) та повна підтримка асинхронності.

---

## 2. Швидкий старт (Setup)
Для початку роботи вам знадобиться сам фреймворк та сервер **uvicorn**, який буде запускати ваш код.

```bash
pip install fastapi uvicorn
```

### Мінімальний додаток (`main.py`)
```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def root():
    return {"message": "Hello World"}
```

**Як запустити:**
У терміналі виконайте:
`uvicorn main:app --reload`
* `main` — назва файлу.
* `app` — назва екземпляра FastAPI.
* `--reload` — автоматичне перезавантаження сервера при зміні коду.

---

## 3. Основні концепції

### Шляхи (Path Parameters)
Це змінні частини URL. FastAPI автоматично конвертує їх у потрібний тип.

```python
@app.get("/items/{item_id}")
async def read_item(item_id: int): # FastAPI перевірить, чи це число
    return {"item_id": item_id}
```

### Параметри запиту (Query Parameters)
Все, що йде після `?` в URL. Якщо ви не вказуєте параметр у шляху, FastAPI вважає його Query-параметром.

```python
@app.get("/users/")
async def get_users(limit: int = 10, offset: int = 0):
    return {"limit": limit, "offset": offset}
```

## 4. Робота з тілом запиту (Pydantic Models)
Це найважливіша частина. Замість того, щоб вручну діставати дані з JSON, ми описуємо схему.



```python
from pydantic import BaseModel
from typing import Optional

class Item(BaseModel):
    name: str
    price: float
    is_offer: Optional[bool] = None

@app.post("/items/")
async def create_item(item: Item):
    return {"item_name": item.name, "total_price": item.price}
```

## 6. Практичне завдання для закріплення
Спробуйте створити міні-сервіс для керування списком завдань (To-Do List):

1.  Створіть модель `Task` з полями: `id` (int), `title` (str), `completed` (bool).
2.  Створіть список `tasks = []` у пам'яті (замість бази даних).
3.  Напишіть `GET` метод, щоб отримати всі завдання.
4.  Напишіть `POST` метод, щоб додати нове завдання.
5.  Напишіть `PUT` метод, щоб оновити статус завдання за його `id`.

### Порада для професіоналів:
Використовуйте асинхронність (`async def`) там, де є очікування (запити до БД, сторонніх API). Для простих обчислень можна використовувати звичайний `def`, FastAPI сам розбереться, як це оптимізувати.

На чому саме ви зупинилися минулого разу? Можливо, варто розібрати підключення до бази даних (наприклад, PostgreSQL або SQLite)?

Чудове доповнення! **Декоратори** та **генератори** — це фундаментальні інструменти Python, які у FastAPI використовуються на кожному кроці. Декоратори відповідають за маршрутизацію (routing), а генератори часто лежать в основі керування ресурсами (наприклад, підключення до БД).

Розглянемо їх детально в контексті веб-розробки.

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel

app = FastAPI()

# 📦 Модель
class Task(BaseModel):
    id: int
    title: str
    completed: bool = False

# 🧠 "База даних"
tasks = []

# 📥 GET — отримати всі задачі
@app.get("/tasks")
def get_tasks():
    return tasks

# ➕ POST — створити задачу
@app.post("/tasks")
def create_task(task: Task):
    tasks.append(task)
    return {"message": "Task created", "task": task}

# ✏️ PUT — оновити статус
@app.put("/tasks/{task_id}")
def update_task(task_id: int, completed: bool):
    for task in tasks:
        if task.id == task_id:
            task.completed = completed
            return {"message": "Task updated", "task": task}
    
    raise HTTPException(status_code=404, detail="Task not found")
```

## 7. Декоратори у FastAPI
У Python декоратор — це функція, яка приймає іншу функцію та розширює її поведінку, не змінюючи її код.

У FastAPI декоратори використовуються для того, щоб сказати серверу: *"Коли прийде запит на цю адресу (URL), виконай цю функцію"*.

### Як це працює:


```python
@app.get("/welcome")  # Це декоратор
def welcome_user():
    return {"message": "Ласкаво просимо!"}
```

* `@app` — це екземпляр класу `FastAPI`.
* `.get("/")` — метод декоратора, який визначає HTTP-метод (GET, POST, тощо) та шлях.

## 8. Генератори та ключове слово `yield`
Генератор — це особливий тип функції, яка повертає значення по одному за раз за допомогою `yield`, зберігаючи свій стан між викликами.

### Чому це важливо для FastAPI?
Найчастіше генератори використовуються в **Dependency Injection** (впровадження залежностей). Наприклад, коли вам потрібно відкрити з'єднання з базою даних, використати його, а потім обов'язково закрити.

```python
def get_db():
    db = DatabaseConnection()
    try:
        yield db  # Передаємо з'єднання в обробник запиту
    finally:
        db.close() # Цей код виконається ПІСЛЯ того, як API віддасть відповідь
```

Завдяки `yield` ми гарантуємо, що ресурси не "потечуть" і база даних завжди буде закрита.

## 9. Практичне застосування (Dependency Injection)

Поєднаємо все разом. Уявімо, що ми хочемо перевіряти "час виконання" запиту за допомогою власного декоратора (для логів) та використовувати генератор для імітації сесії.

```python
import time
from fastapi import FastAPI, Depends

app = FastAPI()

# 1. Генератор для "сесії"
def get_session():
    print("Відкриваємо сесію...")
    session = {"id": "123-ABC"}
    try:
        yield session
    finally:
        print("Закриваємо сесію...")

# 2. Ендпоінт, що використовує залежність (генератор)
@app.get("/secure-data")
async def get_data(session: dict = Depends(get_session)):
    return {"data": "Secret info", "session_id": session["id"]}
```
