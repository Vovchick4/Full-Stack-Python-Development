1. Аналогія «Офіціант у ресторані»
Це класичний спосіб пояснити REST API:

Клієнт (Ви): Сидите за столом і хочете замовити їжу (дані).

Сервер (Кухня): Там готуються дані, але ви не маєте прямого доступу до плити.

API (Офіціант): Приймає ваше замовлення (Request), несе його на кухню, а потім повертає вам тарілку з їжею (Response).

## Практична робота: Створюємо цифрову ресторацію

У цьому сценарії наш сервер буде **Кухнею**, а API — **Офіціантом**, який обробляє замовлення.

### 1. Підготовка (Меню)
Спочатку створимо структуру наших даних. У реальному житті — це меню, у програмуванні — це **Pydantic** моделі.

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel
from typing import List, Optional

app = FastAPI()

# Модель страви (що можна замовити)
class Dish(BaseModel):
    id: int
    name: str
    price: float
    is_ready: bool = False

# Наша "Кухня" (база даних у пам'яті)
menu = [
    {"id": 1, "name": "Піца Маргарита", "price": 250.0, "is_ready": True},
    {"id": 2, "name": "Паста Карбонара", "price": 180.0, "is_ready": False},
]
```

---

### 2. Реалізація «Офіціанта» (Ендпоінти)

Тепер додамо логіку взаємодії. Поясніть новачкам, що кожен метод — це різна дія клієнта в ресторані.

#### **GET /menu — «Подивитися меню»**
Клієнт хоче знати, що є в наявності.
```python
@app.get("/menu")
def get_menu():
    return {"available_dishes": menu}
```

#### **POST /order — «Зробити нове замовлення»**
Клієнт передає офіціанту записку з новою стравою, якої немає в списку.
```python
@app.post("/order")
def create_order(dish: Dish):
    menu.append(dish.dict())
    return {"message": f"Страва '{dish.name}' прийнята в роботу!", "order": dish}
```

#### **PUT /kitchen/{dish_id} — «Оновити статус страви»**
Це дія, яку робить кухар: коли страва готова, він змінює її статус.
```python
@app.put("/kitchen/{dish_id}")
def update_dish_status(dish_id: int, ready: bool):
    for dish in menu:
        if dish["id"] == dish_id:
            dish["is_ready"] = ready
            return {"status": "Оновлено", "dish": dish}
    raise HTTPException(status_code=404, detail="Такої страви не готуємо")
```

### 3. Наочність: Як це працює в JSON
Поясніть студентам, що "офіціант" спілкується особливою мовою — **JSON**. 



Коли ми робимо `GET /menu`, офіціант повертає нам такий "чек":
```json
{
  "available_dishes": [
    {
      "id": 1,
      "name": "Піца Маргарита",
      "price": 250.0,
      "is_ready": true
    }
  ]
}
```

### 4. Завдання для студентів «Зірочка» ⭐️

Щоб закріпити матеріал, самостійно додати метод **DELETE**:
* **Сценарій:** Клієнт передумав і хоче скасувати замовлення (видалити страву з меню/черги).
* **Метод:** `@app.delete("/cancel/{dish_id}")`.
* **Логіка:** Знайти страву за ID у списку `menu` та видалити її.
