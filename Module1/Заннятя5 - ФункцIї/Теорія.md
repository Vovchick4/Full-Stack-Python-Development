# Частина 1 — Що таке функція (30 хв)

## Що таке функція

**Функція — це блок коду, який виконує певну задачу і може викликатися багато разів** ([Learn with Yasir][2]).

Приклад без функції:

```python
print(2 + 3)
print(4 + 7)
print(10 + 5)
```

Ми **повторюємо код**.

---

## Тепер з функцією

```python
def add(a, b):
    print(a + b)

add(2, 3)
add(4, 7)
add(10, 5)
```

Тут:

```
def → ключове слово для створення функції
add → назва функції
(a, b) → параметри
```

# Частина 3 — Параметри функції (30 хв)

Параметри — це **дані, які передаються у функцію**.

```python
def greet(name):
    print("Hello", name)

greet("Ivan")
greet("Anna")
```

Результат:

```
Hello Ivan
Hello Anna
```

---

## Кілька параметрів

```python
def sum_numbers(a, b):
    print(a + b)

sum_numbers(5, 10)
```

# Частина 4 — return (30 хв)

`return` **повертає результат функції**.

Без return:

```python
def add(a, b):
    print(a + b)
```

З return:

```python
def add(a, b):
    return a + b
```

Використання:

```python
result = add(5, 3)

print(result)
```

Результат:

```
8
```

Якщо `return` відсутній — функція повертає **None** ([learnscript.net][3]).

# Частина 6 — Типи функцій у Python (20 хв)

У Python є **3 основні типи функцій**.

---

# 1️⃣ Вбудовані функції (Built-in functions)

Це функції, які вже є в Python.

Приклади:

```python
print()
len()
type()
sum()
max()
min()
```

### Приклад

```python
numbers = [1,2,3,4]

print(len(numbers))
print(max(numbers))
print(sum(numbers))
```

---

# 2️⃣ Власні функції (User-defined functions)

Це функції, які **створює програміст**.

```python
def multiply(a, b):
    return a * b
```

Виклик:

```python
print(multiply(4, 5))
```

---

# 3️⃣ Анонімні функції (lambda)

Маленькі функції в один рядок.

```python
square = lambda x: x * x

print(square(5))
```

# Частина 7 — Методи (20 хв)

### Метод — це функція, яка належить об'єкту.

Наприклад:

```python
text = "hello"

text.upper()
```

Тут:

```
upper() → метод рядка
```

---

### Приклади методів

#### string methods

```python
text = "hello world"

print(text.upper())
print(text.lower())
print(text.replace("world", "Python"))
```

---

#### list methods

```python
numbers = [1,2,3]

numbers.append(4)
numbers.pop()

print(numbers)
```

# Частина 10 — Рекурсія (15 хв)

Функція може викликати **саму себе**.

```python
def factorial(n):
    if n == 1:
        return 1
    return n * factorial(n-1)

print(factorial(5))
```
