
## 1. Списки (Lists) — Твій універсальний інструмент

Список — це впорядкована послідовність елементів, яку можна змінювати. Уяви це як потяг, де ти можеш додавати вагони, відчіпляти їх або змінювати їхній вміст.

* **Створення:** Використовуються квадратні дужки `[]`.
* **Індексація:** Починається з **0**.

```python
# Створюємо список фруктів
fruits = ["яблуко", "банан", "вишня"]

# Змінюємо елемент
fruits[1] = "груша" 

# Додаємо новий елемент в кінець
fruits.append("апельсин")

print(fruits) # Результат: ['яблуко', 'груша', 'вишня', 'апельсин']

```

## 2. Кортежі (Tuples) — Список, який не можна змінити

Кортеж схожий на список, але його вміст **неможливо змінити** після створення. Це корисно для даних, які мають залишатися сталими (наприклад, координати або дні тижня).

* **Створення:** Використовуються круглі дужки `()`.
* **Чому це важливо?** Вони працюють швидше за списки та захищають дані від випадкових змін.

```python
coordinates = (10, 20)
# coordinates[0] = 5  # Це викличе помилку!

```

## 3. Словники (Dictionaries) — Пари "ключ: значення"

Словники дозволяють зберігати дані не за номерами, а за логічними іменами (ключами). Це як справжній словник: ти шукаєш слово (ключ) і отримуєш його опис (значення).

* **Створення:** Використовуються фігурні дужки `{}`.

```python
user = {
    "name": "Олексій",
    "age": 25,
    "city": "Київ"
}

# Отримуємо значення за ключем
print(user["name"]) # Результат: Олексій

```

## Порівняльна таблиця колекцій

| Тип | Дужки | Змінність | Впорядкованість | Призначення |
| --- | --- | --- | --- | --- |
| **List** | `[]` | Так | Так | Послідовні дані, що змінюються |
| **Tuple** | `()` | Ні | Так | Сталі дані, константи |
| **Dict** | `{}` | Так | Так (з Python 3.7) | Дані у форматі "Ключ-Значення" |

## Прохід елементів
Щоб пройтись по всіх елементах у Python для цього найчастіше використовується цикл `for`.

---

## 1. Обхід Списків та Кортежів

Оскільки і списки, і кортежі — це впорядковані послідовності, цикл `for` просто бере по черзі кожен елемент від першого до останнього.

```python
fruits = ["яблуко", "банан", "вишня"]

for fruit in fruits:
    print(f"Я люблю їсти {fruit}")

```

### Використання `enumerate()`

Якщо тобі потрібно знати не тільки сам елемент, а й його **номер (індекс)**, використовуй функцію `enumerate()`:

```python
for index, fruit in enumerate(fruits):
    print(f"{index + 1}. {fruit}") 
# Виведе: 1. яблуко, 2. банан...

```

## 2. Обхід Словників

Зі словниками трохи цікавіше, бо в них є і ключі, і значення. Ти можеш проходитися по ним трьома способами:

### А) Тільки по ключах

```python
user = {"name": "Олексій", "age": 25, "city": "Київ"}

for key in user:
    print(key) # name, age, city

```

### Б) Тільки по значеннях

```python
for value in user.values():
    print(value) # Олексій, 25, Київ

```

### В) І по ключах, і по значеннях (найпопулярніший метод)

Для цього використовується метод `.items()`.

```python
for key, value in user.items():
    print(f"Поле '{key}' містить дані: {value}")

```

## 3. Списки всередині списків (Матриці)

Іноді в нас є список, де кожен елемент — це теж список (як таблиця). Щоб дістатися до кожного елемента, ми використовуємо **вкладені цикли**.

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]

for row in matrix:
    for item in row:
        print(item, end=" ") # Виведе всі числа в ряд

```
