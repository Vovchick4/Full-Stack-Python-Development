У квадратній матриці (де кількість рядків дорівнює кількості стовпців) є дві головні діагоналі:

1. **Головна діагональ:** йде з верхнього лівого кута в нижній правий.
2. **Побічна діагональ:** йде з верхнього правого кута в нижній лівий.

---

## 1. Секрет індексів діагоналей

Щоб ефективно працювати з діагоналями, треба знати "магічне" правило індексів:

* Для **головної** діагоналі: номер рядка **дорівнює** номеру стовпця ().
* Для **побічної** діагоналі: сума індексів рядка та стовпця завжди **дорівнює ** (де  — розмір матриці).

---

## 2. Практичний приклад: Заміна діагоналей

Давай створимо матрицю  і замінимо всі елементи на головній діагоналі на число `0`, а на побічній — на число `1`.

```python
# Створюємо матрицю 3x3
matrix = [
    [5, 8, 2],
    [3, 6, 7],
    [1, 4, 9]
]

n = len(matrix) # Розмір матриці (3)

for i in range(n): # Проходимо по рядках
    for j in range(n): # Проходимо по стовпцях
        
        # Перевірка для головної діагоналі (0,0), (1,1), (2,2)
        if i == j:
            matrix[i][j] = 0
            
        # Перевірка для побічної діагоналі (0,2), (1,1), (2,0)
        elif i + j == n - 1:
            matrix[i][j] = 1

# Виводимо результат красиво
for row in matrix:
    print(row)

```

**Що вийде в консолі:**

```text
[0, 8, 1]
[3, 0, 7]
[1, 4, 0]

```

*(Примітка: в центрі (індекс 1,1) елемент головної діагоналі перекрив побічну, бо `if` спрацював першим).*

---

## 3. Оптимізація (Просунутий рівень)

Насправді нам не обов'язково перевіряти кожну клітинку двома циклами. Можна зробити це одним циклом, знаючи координати:

```python
for i in range(n):
    matrix[i][i] = "X"          # Головна діагональ
    matrix[i][n - 1 - i] = "O"  # Побічна діагональ

```
