# 📘 УРОК: Обробка помилок (Exceptions) в Python

---

# 🧠 1. Що таке помилка (Exception)

**Exception** — це помилка, яка виникає під час виконання програми.

Наприклад:

```python
print(10 / 0)
```

👉 отримаємо:

```
ZeroDivisionError
```

---

# ⚙️ 2. try / except

Основна конструкція:

```python
try:
    # код, який може впасти
except:
    # що робити при помилці
```

---

## ✅ Приклад

```python
try:
    x = 10 / 0
except:
    print("Сталася помилка")
```

---

# 🎯 3. Ловимо конкретні помилки

Краще **не ловити все підряд**, а конкретну помилку:

```python
try:
    x = int("abc")
except ValueError:
    print("Це не число")
```

---

# 🔍 4. Кілька except

```python
try:
    x = int("abc")
except ValueError:
    print("Помилка конвертації")
except TypeError:
    print("Помилка типу")
```

---

# 🧾 5. Отримати текст помилки

```python
try:
    x = 10 / 0
except Exception as e:
    print(e)
```

👉 виведе:

```
division by zero
```

---

# 🚫 6. finally

`finally` виконується **завжди**:

```python
try:
    x = 10 / 0
except:
    print("Помилка")
finally:
    print("Це виконається завжди")
```

---

# ✅ 7. else

`else` виконується, якщо **помилки не було**

```python
try:
    x = 10 / 2
except:
    print("Помилка")
else:
    print("Все ок")
```

---

# 🔥 8. Повна структура

```python
try:
    x = int("123")
except ValueError:
    print("Помилка")
else:
    print("Успіх")
finally:
    print("Кінець")
```

---

# ⚠️ 9. Викидання помилки (raise)

Можеш сам створити помилку:

```python
raise ValueError("Щось не так")
```

---

## ✅ Приклад

```python
age = -5

if age < 0:
    raise ValueError("Вік не може бути від’ємним")
```

---

# 🧱 10. Кастомні помилки

```python
class MyError(Exception):
    pass

raise MyError("Моя помилка")
```

---

# 💡 11. Best Practices

### ❌ Погано

```python
try:
    ...
except:
    pass
```

👉 ти “ковтаєш” помилку

---

### ✅ Добре

```python
except Exception as e:
    print(e)
```

---

### ❌ Не роби так

```python
except Exception:
    # логіка
```

👉 краще ловити конкретні помилки

---

# 🧠 12. Реальний приклад

```python
try:
    user_input = input("Введи число: ")
    number = int(user_input)
    print(10 / number)
except ValueError:
    print("Введи число!")
except ZeroDivisionError:
    print("Не можна ділити на 0")
```

---

# 🚀 Висновок

* `try` — пробуємо виконати
* `except` — ловимо помилку
* `else` — якщо все ок
* `finally` — виконується завжди
* `raise` — кидаємо помилку
