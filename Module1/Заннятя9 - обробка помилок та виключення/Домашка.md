# 🧠 ТЕСТ: Python Exceptions

---

## ✅ 1. Що виведе код?

```python
try:
    print(10 / 0)
except ZeroDivisionError:
    print("Error")
```

A) 10
B) Error
C) Exception

👉 **Відповідь: B**

**Чому:** виникає `ZeroDivisionError`, ми його ловимо.

---

## ✅ 2. Що виведе?

```python
try:
    int("abc")
except ValueError:
    print("Value error")
except Exception:
    print("Other error")
```

👉 **Відповідь: Value error**

**Чому:** перший підходящий `except` спрацьовує.

---

## ✅ 3. Що виведе?

```python
try:
    print("Hello")
except:
    print("Error")
else:
    print("OK")
```

👉 **Відповідь:**

```
Hello
OK
```

**Чому:** помилки не було → виконується `else`.

---

## ✅ 4. Що зробить finally?

```python
try:
    x = 1 / 0
except:
    print("Error")
finally:
    print("Done")
```

👉 **Відповідь:**

```
Error
Done
```

**Чому:** `finally` виконується завжди.

---

## ✅ 5. Що виведе?

```python
try:
    x = int("5")
except:
    print("Error")
else:
    print(x)
```

👉 **Відповідь: 5**

---

## ✅ 6. Що виведе?

```python
try:
    raise ValueError("Test")
except ValueError as e:
    print(e)
```

👉 **Відповідь: Test**

---

## ✅ 7. Що погано в коді?

```python
try:
    x = 10 / 0
except:
    pass
```

👉 **Відповідь:**
Помилка **ігнорується** → важко дебажити

---

## ✅ 8. Що виведе?

```python
try:
    print(10 / 0)
except Exception:
    print("Error")
except ZeroDivisionError:
    print("Zero")
```

👉 **Відповідь: Error**

**Чому:** `Exception` ловить ВСЕ → до другого except не дійде

---

## ✅ 9. Що станеться?

```python
def test():
    try:
        return 1
    finally:
        return 2
```

👉 **Відповідь: 2**

**Чому:** `finally` перезаписує return

---

## ✅ 10. Яка помилка?

```python
print(a)
```

A) ValueError
B) NameError
C) TypeError

👉 **Відповідь: B (NameError)**

# 🧪 ПРАКТИЧНЕ ЗАВДАННЯ

## 🔥 Умова

Напиши програму:

1. Користувач вводить число
2. Якщо:

   * не число → "Це не число"
   * 0 → "Не можна ділити на 0"
3. Інакше → вивести:

```python
100 / число
```

---

# ✅ РІШЕННЯ

```python
try:
    user_input = input("Введи число: ")
    number = int(user_input)

    if number == 0:
        raise ZeroDivisionError

    result = 100 / number
    print(result)

except ValueError:
    print("Це не число")

except ZeroDivisionError:
    print("Не можна ділити на 0")
```

---

# 💡 Висновок

* лови **конкретні помилки**
* не використовуй `except: pass`
* `finally` може змінити логіку
* `raise` — для власних перевірок
