# Частина 1 — Що таке модулі (25 хв)

## 1. Проблема великих програм

Коли програма стає великою:

* 1000+ рядків коду
* багато функцій
* різні логічні частини

Все в одному файлі стає:

* важко читати
* важко підтримувати
* важко перевикористовувати

Тому програму **розбивають на модулі**.

---

## 2. Що таке модуль

**Модуль** — це звичайний Python файл (`.py`), який містить:

* функції
* класи
* змінні
* код

Приклад:

```
math_utils.py
```

```
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b
```

Це **модуль**.

---

## 3. Імпорт модуля

Щоб використати модуль:

```
import math_utils
```

```
print(math_utils.add(2, 3))
```

Результат

```
5
```

Python шукає файл **math_utils.py**.

---

## 4. Як працює імпорт

```
import module
```

Python:

1️⃣ знаходить файл
2️⃣ виконує код
3️⃣ створює об'єкт модуля

---

## 5. Простий приклад

Файл:

```
calculator.py
```

```
def sum(a, b):
    return a + b
```

Файл:

```
main.py
```

```
import calculator

print(calculator.sum(10, 5))
```

# Частина 2 — Варіанти імпорту (20 хв)

## 1. import module

```
import math

print(math.sqrt(16))
```

---

## 2. import module as alias

Можна зробити коротку назву.

```
import math as m

print(m.sqrt(16))
```

---

## 3. from module import function

```
from math import sqrt

print(sqrt(16))
```

---

## 4. імпорт кількох функцій

```
from math import sqrt, pow
```

---

## 5. імпорт всього

```
from math import *
```

⚠️ **Не рекомендується**.

Чому:

* конфлікти імен
* складно читати код

# Частина 3 — Вбудовані модулі Python (15 хв)

Python має **стандартну бібліотеку**.

Деякі популярні модулі:

| Модуль   | Для чого            |
| -------- | ------------------- |
| math     | математичні функції |
| random   | випадкові числа     |
| datetime | дата і час          |
| os       | робота з ОС         |
| sys      | системна інформація |

---

## Приклад random

```
import random

print(random.randint(1, 10))
```

---

## Приклад datetime

```

```

# Частина 5 — Що таке пакети (25 хв)

Коли модулів стає багато, їх об'єднують у **пакети**.

**Пакет** — це папка з модулями.

---

## Структура пакету

```
project/

main.py

utils/
    math_utils.py
    string_utils.py
```

---

## Імпорт з пакету

```
from utils import math_utils
```

```
print(math_utils.add(2,3))
```

---

## Імпорт функції

```
from utils.math_utils import add
```

```
print(add(5,6))
```

---

# Частина 6 — **init**.py (10 хв)

Раніше Python вимагав файл:

```
__init__.py
```

Щоб позначити **пакет**.

Структура:

```
utils/
    __init__.py
    math_utils.py
```

---

### Що робить `__init__.py`

* ініціалізує пакет
* може виконувати код
* може визначати що експортувати

Приклад:

```
from .math_utils import add
```

Тоді можна:

```
from utils import add
```
