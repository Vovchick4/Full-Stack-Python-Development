## 2. Встановлення Python

### Кроки:

1. Перейди на офіційний сайт: [https://www.python.org](https://www.python.org)
2. Натисни **Download Python**
3. Під час встановлення **обовʼязково постав галочку**:
   ☑ Add Python to PATH
4. Натисни **Install**

## 10. Типи даних (коротко)

```python
text = "Hello"      # str (string), Рядок символів (наприклад, "Привіт, світ").
number = 10          # int (integer), Цілі числа (наприклад, 1, 100, -50)
price = 9.99         # float, Дробові числа з рухомою крапкою (наприклад, 3.14, -0.01)
is_active = True     # bool (boolean), Логічні значення, що приймають лише два стани: true (істина) або false (хибність).
```
