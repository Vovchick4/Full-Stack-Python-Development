# Гарячі клавіші Visual Studio Code

## Шпаргалка для початківців 🚀

Visual Studio Code (VS Code) — це потужний редактор коду. Знання гарячих клавіш допоможе працювати значно швидше.

---

## 📂 Робота з файлами

| Дія           | Windows / Linux    | Mac               |
| ------------- | ------------------ | ----------------- |
| Новий файл    | `Ctrl + N`         | `Cmd + N`         |
| Відкрити файл | `Ctrl + O`         | `Cmd + O`         |
| Зберегти      | `Ctrl + S`         | `Cmd + S`         |
| Зберегти як   | `Ctrl + Shift + S` | `Cmd + Shift + S` |
| Закрити файл  | `Ctrl + W`         | `Cmd + W`         |

---

## 🔎 Пошук та навігація

| Дія              | Windows / Linux    | Mac               |
| ---------------- | ------------------ | ----------------- |
| Пошук у файлі    | `Ctrl + F`         | `Cmd + F`         |
| Заміна           | `Ctrl + H`         | `Cmd + H`         |
| Пошук по проєкту | `Ctrl + Shift + F` | `Cmd + Shift + F` |
| Перейти до файлу | `Ctrl + P`         | `Cmd + P`         |
| Перейти до рядка | `Ctrl + G`         | `Cmd + G`         |

---

## ✏️ Редагування коду

| Дія                          | Windows / Linux    | Mac                  |
| ---------------------------- | ------------------ | -------------------- |
| Копіювати                    | `Ctrl + C`         | `Cmd + C`            |
| Вставити                     | `Ctrl + V`         | `Cmd + V`            |
| Вирізати                     | `Ctrl + X`         | `Cmd + X`            |
| Копіювати рядок вниз         | `Shift + Alt + ↓`  | `Shift + Option + ↓` |
| Видалити рядок               | `Ctrl + Shift + K` | `Cmd + Shift + K`    |
| Перемістити рядок вгору/вниз | `Alt + ↑ / ↓`      | `Option + ↑ / ↓`     |
| Коментувати рядок            | `Ctrl + /`         | `Cmd + /`            |
| Форматувати код              | `Shift + Alt + F`  | `Shift + Option + F` |

---

## 🖥 Робота з вікнами

| Дія                       | Windows / Linux    | Mac                |
| ------------------------- | ------------------ | ------------------ |
| Відкрити термінал         | `Ctrl + ~`         | `Cmd + ~`          |
| Нова вкладка терміналу    | `Ctrl + Shift + ~` | `Cmd + Shift + ~`  |
| Розділити редактор        | `Ctrl + \`         | `Cmd + \`          |
| Перемикання між вкладками | `Ctrl + Tab`       | `Cmd + Option + →` |

---

## ⚡ Корисні універсальні

| Дія                   | Windows / Linux    | Mac               |
| --------------------- | ------------------ | ----------------- |
| Command Palette       | `Ctrl + Shift + P` | `Cmd + Shift + P` |
| Відкрити налаштування | `Ctrl + ,`         | `Cmd + ,`         |
| Відкрити Extensions   | `Ctrl + Shift + X` | `Cmd + Shift + X` |

---

## 🎯 ТОП-12 найважливіших для старту

1. `Ctrl + S` — зберегти
2. `Ctrl + C` — копіювати
3. `Ctrl + V` — вставити
4. `Ctrl + /` — коментар
5. `Ctrl + P` — швидкий пошук файлу
6. `Ctrl + Shift + P` — всі команди
7. `Shift + Alt + ↓` — копія рядка
8. `Alt + ↑/↓` — перемістити рядок
9. `Ctrl + F` — пошук
10. `Ctrl + Shift + F` — пошук по проєкту
11. `Ctrl + ~` — відкрити термінал
12. `Shift + Alt + F` — форматувати код

---

## 💡 Порада для початківців

Навіть базові комбінації (`Ctrl + C`, `Ctrl + V`, `Ctrl + S`) вже значно пришвидшують роботу. Намагайтеся мінімізувати використання мишки — це суттєво підвищує продуктивність 💪
