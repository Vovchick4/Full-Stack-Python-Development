## 1. Введення даних: функція `input()`

Щоб програма стала інтерактивною, вона має "чути" користувача.

```python
name = input("Як тебе звати? ")
print("Привіт, " + name + "!")

```

> ⚠️ **Важливо:** `input()` завжди повертає текст (**str**). Якщо потрібне число, використовуй `int()`:
> `age = int(input("Скільки тобі років? "))`

Функція `input()` зупиняє виконання програми та чекає, поки користувач введе текст і натисне **Enter**.

> **Важливо:** Все, що вводить користувач, Python сприймає як **рядок (string)**.

### Приклади конвертації типів:

```python
# Для тексту
city = input("З якого ти міста? ")

# Для цілих чисел (int)
count = int(input("Скільки яблук ти хочеш? "))

# Для дробових чисел (float)
price = float(input("Введи ціну товару: "))
```

## 2. Умовні оператори (if, elif, else)

**Умовний оператор** — це конструкція, яка дозволяє програмі виконувати різні блоки коду залежно від того, чи є певна умова істинною (**True**) чи хибною (**False**). Це "серце" логіки будь-якого додатка.

### 🧩 Як це працює (Теорія)

Програма перевіряє умову зверху вниз:
1. **`if` (якщо):** Перша перевірка. Якщо вона істинна, виконується лише цей блок.
2. **`elif` (інакше якщо):** Перевіряється тільки тоді, коли попередні умови були хибними. Таких блоків може бути скільки завгодно.
3. **`else` (інакше):** "Запасний варіант". Виконується, якщо жодна з попередніх умов не спрацювала.

---

### ⚖️ Оператори порівняння та логічний тип `bool`

Результатом будь-якого порівняння є тип даних **Boolean** (булевий), який має лише два значення: `True` (Так) або `False` (Ні).

| Оператор | Опис | Приклад (`x = 5`) |
| :--- | :--- | :--- |
| `==` | Рівність (не плутати з `=`!) | `x == 5` -> `True` |
| `!=` | Не дорівнює | `x != 5` -> `False` |
| `>` / `<` | Більше / Менше | `x > 3` -> `True` |
| `>=` / `<=` | Більше/менше або рівно | `x <= 5` -> `True` |

---

### 🔗 Комбінування умов (Логічні оператори)

Іноді потрібно перевірити кілька умов одночасно. Для цього використовують логічні зв'язки:

1.  **`and` (ТА):** Умова істинна, лише якщо **обидві** частини істинні.
    * *Приклад:* `if age >= 18 and has_money >= 100:` (Повнолітній ТА має гроші).
2.  **`or` (АБО):** Умова істинна, якщо хоча б **одна** з частин істинна.
    * *Приклад:* `if day == "Субота" or day == "Неділя":` (Сьогодні вихідний).
3.  **`not` (НЕ):** Інвертує результат (робить True хибним і навпаки).
    * *Приклад:* `if not is_raining:` (Якщо НЕ йде дощ).

### 🏗️ Складна структура (Вкладені умови)

Ви можете ставити один `if` всередину іншого. Це називається вкладеністю.

```python
is_member = True
balance = 150

if is_member:
    if balance > 100:
        print("Ви VIP-гість і маєте достатньо коштів.")
    else:
        print("Ви член клубу, але поповніть баланс.")
else:
    print("Будь ласка, спочатку зареєструйтесь.")
```

## 3. Цикл `while` (поки)

Виконує код доти, доки умова є істинною (**True**).

```python
count = 1
while count <= 5:
    print("Крок №", count)
    count += 1  # збільшуємо на 1, щоб цикл не був вічним

```

🔹 **Вічний цикл:** Якщо забути змінити змінну умови, програма буде працювати вічно (зупинити: `Ctrl + C` у терміналі).

## 4. Цикл `for` та функція `range()`

Використовується, коли ми знаємо кількість повторень або перебираємо елементи.

```python
# Виведе числа від 0 до 4
for i in range(5):
    print("Ітерація:", i)

```

* `range(5)` — генерує послідовність: 0, 1, 2, 3, 4.
* `range(1, 6)` — генерує послідовність: 1, 2, 3, 4, 5.

---

## 5. Керування циклами: `break` та `continue`

* **`break`** — повністю зупиняє цикл.
* **`continue`** — пропускає поточну ітерацію і переходить до наступної.

```python
for num in range(1, 10):
    if num == 5:
        break  # Цикл зупиниться на 5
    print(num)

```

## 6. Типові помилки

❌ **Відступи (Indentation):** У Python відступи (4 пробіли або Tab) є обов'язковими після двокрапки `:`.

```python
if True:
print("Помилка!") # Неправильно
    print("Правильно") # Правильно

```

❌ **Плутанина `=` та `==`:** * `=` — присвоєння значення.

* `==` — перевірка на рівність.
