# 🧠 Практичні завдання з реалізацією (Python)

## 1️⃣ Перевірка віку

### 📌 Умова:

* запитати у користувача його вік;
* якщо менше 18 — `"Доступ заборонено"`;
* якщо 18 і більше — `"Доступ дозволено"`.

### 💻 Реалізація:

```python
age = int(input("Введіть ваш вік: "))

if age < 18:
    print("Доступ заборонено")
else:
    print("Доступ дозволено")
```

## 2️⃣ Калькулятор парності

### 📌 Умова:

* запитати число;
* перевірити, чи воно парне;
* вивести відповідне повідомлення.

### 💻 Реалізація:

```python
number = int(input("Введіть число: "))

if number % 2 == 0:
    print("Парне число")
else:
    print("Непарне число")
```

---

## 3️⃣ Таблиця множення

### 📌 Умова:

* запитати число;
* вивести таблицю множення від 1 до 10;
* використати цикл `for`.

### 💻 Реалізація:

```python
number = int(input("Введіть число для таблиці множення: "))

for i in range(1, 11):
    print(f"{number} x {i} = {number * i}")
```

---

## 4️⃣ Сума чисел

### 📌 Умова:

* запитати число `N`;
* знайти суму чисел від 1 до `N`;
* використати цикл `for`.

### 💻 Реалізація:

```python
n = int(input("Введіть число N: "))

total = 0

for i in range(1, n + 1):
    total += i

print("Сума чисел:", total)
```

---

## 5️⃣ Лічильник до 0

### 📌 Умова:

* запитати число;
* за допомогою `while` зменшувати його до 0;
* виводити кожен крок.

### 💻 Реалізація:

```python
number = int(input("Введіть число: "))

while number >= 0:
    print(number)
    number -= 1
```
