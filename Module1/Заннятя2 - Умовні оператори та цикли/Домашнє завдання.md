## 🧠 Додаткові практичні завдання

### 1️⃣ Калькулятор суми чисел

**Завдання:**
Користувач вводить число `n`. Програма повинна порахувати суму чисел від 1 до `n`.

**Вимоги:**

* Використати `input`
* Використати цикл `for`
* Вивести результат

**Приклад:**

```
Введи число: 5
Сума = 15
```

---

### 2️⃣ Перевірка парності числа

**Завдання:**
Користувач вводить число. Програма повинна визначити — воно парне чи непарне.

**Вимоги:**

* `input`
* `if/else`
* Оператор `%` (залишок від ділення)

**Підказка:**

```python
number % 2 == 0
```

---

### 3️⃣ Лічильник спроб (while)

**Завдання:**
Користувач має 3 спроби ввести правильний пароль `"python"`.
Якщо пароль правильний — вивести "Доступ дозволено".
Якщо після 3 спроб пароль неправильний — "Спроби закінчились".

**Вимоги:**

* `while`
* `if/else`
* Лічильник спроб

---

### 4️⃣ Таблиця множення

**Завдання:**
Користувач вводить число. Програма виводить таблицю множення цього числа від 1 до 10.

**Приклад:**

```
Введи число: 3
3 x 1 = 3
3 x 2 = 6
...
3 x 10 = 30
```

**Вимоги:**

* `input`
* `for`
* Форматований вивід

---

### 5️⃣ Сума введених чисел (завершення через 0)

**Завдання:**
Користувач вводить числа.
Програма додає їх до загальної суми.
Якщо користувач вводить `0` — програма завершується і показує загальну суму.

**Приклад:**

```
Введи число: 5
Введи число: 3
Введи число: 2
Введи число: 0
Загальна сума: 10
```

**Вимоги:**

* `while`
* `if`
* Накопичення змінної (sum)
