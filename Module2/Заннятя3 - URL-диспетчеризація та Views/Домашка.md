## Домашнє завдання: URL-диспетчеризація та Views

### Завдання 1. Базові маршрути
Створіть додаток `shop` з наступними маршрутами:
- `/` — головна сторінка магазину
- `/products/` — список всіх товарів
- `/products/<int:pk>/` — деталі товару
- `/products/category/<slug:cat_slug>/` — товари категорії
- `/about/` — сторінка "Про нас"
- `/contact/` — сторінка контактів

### Завдання 2. Обробка запитів
Створіть view-функції, які:
1. На головній сторінці повертають HTML з привітанням
2. На сторінці товарів рендерять шаблон зі списком товарів (імітуйте список у пам'яті)
3. На сторінці деталей товару повертають 404, якщо товар не знайдено
4. Обробляють POST запит на створення товару (без збереження в БД, просто поверніть дані назад)

### Завдання 3. Простір імен
1. Додайте `app_name = 'shop'` у файл маршрутів
2. Створіть головний `urls.py` проекту, який включає маршрути додатку
3. Додайте URL для адмін-панелі

### Завдання 4 (⭐ Зірочка)
Створіть view, яка:
- Приймає GET параметр `?search=...`
- Повертає JSON зі списком товарів, відфільтрованих за назвою
- Використовує `JsonResponse`

### Критерії прийому:
- Всі маршрути працюють та повертають коректні HTTP статуси
- Використано `app_name` та `name` для всіх маршрутів
- Код відповідає PEP 8
- Додаток підключено в `INSTALLED_APPS`
