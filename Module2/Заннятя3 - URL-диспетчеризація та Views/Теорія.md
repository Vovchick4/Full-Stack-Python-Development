## 1. URL-диспетчеризація в Django

Django використовує **URLconf** (URL configuration) для маршрутизації запитів. Коли користувач переходить за адресою, Django проходить по всіх URL-шаблонах, поки не знайде відповідність.

### Як це працює:
1. Запит потрапляє в `ROOT_URLCONF` (settings.py)
2. Django проходить по `urlpatterns` зверху вниз
3. При першому збігу викликається відповідна view-функція

```python
# mysite/urls.py (головний)
from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path('admin/', admin.site.urls),
    path('blog/', include('blog.urls')),  # передаємо маршрутизацію додатку
]
```

## 2. Path-функції та конвертери

```python
from django.urls import path
from . import views

app_name = 'blog'  # простір імен

urlpatterns = [
    path('', views.index, name='home'),
    path('about/', views.about, name='about'),
    path('post/<int:pk>/', views.post_detail, name='post_detail'),
    path('posts/<int:year>/<int:month>/', views.post_archive, name='archive'),
    path('category/<slug:category_slug>/', views.category_view, name='category'),
]
```

### Вбудовані конвертери:
| Конвертер | Опис | Приклад |
|-----------|------|---------|
| `str` | Будь-який рядок (без слешів) | `hello/` |
| `int` | Ціле число | `123/` |
| `slug` | Slug (літери, цифри, дефіси) | `my-post-title/` |
| `uuid` | UUID | `550e8400-.../` |
| `path` | Будь-який рядок (зі слешами) | `path/to/file/` |

## 3. Function-Based Views (FBV)

Найпростіший спосіб створення view — функція, яка приймає `request` та повертає `HttpResponse`.

```python
from django.http import HttpResponse, JsonResponse, Http404
from django.shortcuts import render, get_object_or_404, redirect
from .models import Post

# Проста відповідь
def index(request):
    return HttpResponse("Hello, world!")

# Рендер шаблону
def post_list(request):
    posts = Post.objects.filter(is_published=True)
    return render(request, 'blog/post_list.html', {'posts': posts})

# Отримання об'єкту або 404
def post_detail(request, pk):
    post = get_object_or_404(Post, pk=pk, is_published=True)
    return render(request, 'blog/post_detail.html', {'post': post})

# Редирект
def redirect_view(request):
    return redirect('blog:home')

# JSON відповідь
def api_view(request):
    data = {'posts': list(Post.objects.values())}
    return JsonResponse(data)

# Обробка POST запиту
def create_post(request):
    if request.method == 'POST':
        title = request.POST.get('title')
        Post.objects.create(title=title)
        return redirect('blog:home')
    return render(request, 'blog/create_post.html')
```

## 5. HttpRequest та HttpResponse

```python
from django.http import HttpResponse

def custom_response(request):
    # Статус-коди
    response = HttpResponse("OK", status=200)
    response = HttpResponse(status=201)  # Created
    response = HttpResponse(status=400)  # Bad Request
    response = HttpResponse(status=404)  # Not Found

    # Заголовки
    response = HttpResponse()
    response['Content-Type'] = 'application/json'
    response['X-Custom-Header'] = 'value'

    # Cookies
    response.set_cookie('key', 'value', max_age=3600)
    response.delete_cookie('key')

    return response
```

## 6. Статичні маршрути та include()

```python
from django.urls import path, include, re_path

urlpatterns = [
    # Включення інших URLconf
    path('blog/', include('blog.urls')),
    path('api/', include('api.urls')),

    # Регулярні вирази (застарілий спосіб)
    re_path(r'^posts/(?P<year>[0-9]{4})/$', views.posts_by_year),

    # Статичні маршрути (повинні бути внизу)
    path('robots.txt', views.robots_txt),
]
```
