## Домашнє завдання: Шаблони Django

### Завдання 1. Базовий шаблон
Створіть базовий шаблон `base.html` з:
- Заголовком сайту
- Навігацією (Головна, Блог, Про нас, Контакти)
- Блоком `content`
- Підвалом (footer)
- Підключенням статичних файлів (CSS)

### Завдання 2. Сторінки з наслідуванням
Створіть 3 сторінки, які наслідують `base.html`:
1. **Головна** — привітання та останні 3 новини
2. **Список постів** — вивід всіх постів з пагінацією
3. **Деталі посту** — повний текст посту з датою та автором

### Завдання 3. Робота з фільтрами
У шаблоні списку постів застосуйте:
- `truncatewords:20` для тексту
- `date:"d F Y"` для дати
- `linebreaks` для контенту в деталях
- `default:"Анонім"` для автора

### Завдання 4. Кастомний тег
Створіть `templatetags` з:
- Фільтром `read_time`, який рахує час читання (слів / 200 хвилин)
- Тегом `popular_posts`, який виводить 5 найпопулярніших постів

### Критерії прийому:
- Всі шаблони використовують наслідування від `base.html`
- Статичні файли підключено коректно
- Кастомні теги та фільтри працюють
- Використано `{% url %}` для всіх посилань
