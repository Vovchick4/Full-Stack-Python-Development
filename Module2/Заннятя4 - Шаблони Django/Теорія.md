## 1. Що таке Django Template Language (DTL)?

DTL — це вбудована система шаблонів Django, яка дозволяє динамічно генерувати HTML, поєднуючи HTML-розмітку з даними з Python.

Шаблони зберігаються в папці `templates/` всередині додатку або проекту.

```
blog/
└── templates/
    └── blog/
        ├── base.html
        ├── post_list.html
        └── post_detail.html
```

## 2. Змінні та фільтри

### Змінні
```html
<!-- post_list.html -->
<h1>{{ title }}</h1>
<p>Автор: {{ post.author.name }}</p>
<p>Створено: {{ post.created_at }}</p>
```

### Фільтри
```html
{{ text|lower }}                    <!-- перетворює в нижній регістр -->
{{ text|upper }}                    <!-- у верхній регістр -->
{{ text|capfirst }}                 <!-- перша буква велика -->
{{ text|truncatewords:10 }}         <!-- обрізає до 10 слів -->
{{ text|linebreaks }}               <!-- перетворює \n на <br> -->
{{ date|date:"d.m.Y" }}             <!-- форматування дати -->
{{ number|default:"0" }}            <!-- значення за замовчуванням -->
{{ items|length }}                  <!-- довжина списку -->
{{ items|join:", " }}               <!-- об'єднання списку -->
{{ html|safe }}                     <!-- виводить HTML без екранування -->
{{ value|floatformat:2 }}           <!-- форматування числа -->
```

## 3. Теги керування

### if/elif/else
```html
{% if user.is_authenticated %}
    <p>Вітаємо, {{ user.username }}!</p>
{% elif user.is_staff %}
    <p>Вітаємо, адміністраторе!</p>
{% else %}
    <p>Будь ласка, увійдіть.</p>
{% endif %}
```

### for
```html
<ul>
{% for post in posts %}
    <li>
        <a href="{% url 'blog:detail' post.id %}">{{ post.title }}</a>
        {% if forloop.first %}<span>(Перший)</span>{% endif %}
    </li>
{% empty %}
    <li>Немає постів</li>
{% endfor %}
</ul>

<!-- Змінні циклу: forloop.counter, forloop.first, forloop.last -->
```

### with (збереження значення)
```html
{% with total=items|length %}
    <p>Всього товарів: {{ total }}</p>
{% endwith %}
```

## 4. Наслідування шаблонів

### base.html (базовий шаблон)
```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}Мій сайт{% endblock %}</title>
    <link rel="stylesheet" href="{% static 'css/style.css' %}">
</head>
<body>
    <header>
        <nav>
            <a href="{% url 'home' %}">Головна</a>
            <a href="{% url 'blog:list' %}">Блог</a>
        </nav>
    </header>

    <main>
        {% block content %}
        {% endblock %}
    </main>

    <footer>
        <p>&copy; 2026 Мій сайт</p>
    </footer>
</body>
</html>
```

### post_list.html (дочірній шаблон)
```html
{% extends 'blog/base.html' %}

{% block title %}Список постів{% endblock %}

{% block content %}
    <h1>Мій блог</h1>
    {% for post in posts %}
        <article>
            <h2>{{ post.title }}</h2>
            <p>{{ post.content|truncatewords:30 }}</p>
            <a href="{% url 'blog:detail' post.id %}">Читати далі</a>
        </article>
    {% endfor %}
{% endblock %}
```

## 5. Статичні файли

### Налаштування (settings.py)
```python
STATIC_URL = 'static/'
STATICFILES_DIRS = [BASE_DIR / 'static']
STATIC_ROOT = BASE_DIR / 'staticfiles'

MEDIA_URL = 'media/'
MEDIA_ROOT = BASE_DIR / 'media'
```

### Використання в шаблонах
```html
{% load static %}

<link rel="stylesheet" href="{% static 'css/style.css' %}">
<script src="{% static 'js/main.js' %}"></script>
<img src="{% static 'images/logo.png' %}" alt="Logo">
```

## 6. URL-теги

```html
<!-- По імені маршруту -->
<a href="{% url 'blog:detail' post.id %}">Деталі</a>

<!-- З параметрами -->
<a href="{% url 'blog:archive' year=2024 month=3 %}">Архів</a>

<!-- Активне посилання -->
<a href="{% url 'home' %}" {% if request.path == '/' %}class="active"{% endif %}>
    Головна
</a>
```

## 7. Включення інших шаблонів (include)

```html
<!-- post_card.html -->
<div class="card">
    <h3>{{ post.title }}</h3>
    <p>{{ post.content|truncatewords:20 }}</p>
</div>

<!-- post_list.html -->
{% for post in posts %}
    {% include "blog/post_card.html" %}
{% endfor %}
```

## 8. Кастомні фільтри та теги

Створіть `templatetags/` у вашому додатку:

```
blog/
└── templatetags/
    ├── __init__.py
    └── blog_extras.py
```

```python
# blog_extras.py
from django import template
from django.utils.html import format_html

register = template.Library()

@register.filter(name='censor')
def censor(value, word):
    return value.replace(word, '***')

@register.simple_tag
def total_posts():
    from ..models import Post
    return Post.objects.count()

@register.inclusion_tag('blog/post_card.html')
def show_latest_posts(count=5):
    from ..models import Post
    return {'posts': Post.objects.all()[:count]}
```

```html
{% load blog_extras %}

{{ text|censor:"погане_слово" }}
<p>Всього постів: {% total_posts %}</p>
{% show_latest_posts 3 %}
```
