## 1. Статичні та медіа файли

У Django є два типи файлів:
- **Static files** — CSS, JS, зображення для дизайну (керує розробник)
- **Media files** — файли, які завантажують користувачі (аватарки, документи)

### Налаштування (settings.py)
```python
# Статичні файли
STATIC_URL = 'static/'
STATICFILES_DIRS = [BASE_DIR / 'static']  # додаткові папки
STATIC_ROOT = BASE_DIR / 'staticfiles'    # для production (collectstatic)

# Медіа файли
MEDIA_URL = 'media/'
MEDIA_ROOT = BASE_DIR / 'media'
```

### URL-конфігурація для медіа (розробка)
```python
# mysite/urls.py
from django.conf import settings
from django.conf.urls.static import static

urlpatterns = [
    # ... ваші URL
]

if settings.DEBUG:
    urlpatterns += static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

## 3. Завантаження файлів через форми

### ModelForm з файлами
```python
from django import forms
from .models import Profile

class ProfileForm(forms.ModelForm):
    class Meta:
        model = Profile
        fields = ['avatar', 'bio', 'birth_date']
```

### View для завантаження
```python
from django.shortcuts import render, redirect
from .forms import ProfileForm

def upload_avatar(request):
    if request.method == 'POST':
        form = ProfileForm(request.POST, request.FILES, instance=request.user.profile)
        if form.is_valid():
            form.save()
            return redirect('profile')
    else:
        form = ProfileForm(instance=request.user.profile)
    return render(request, 'upload_avatar.html', {'form': form})
```

### Шаблон (важливо: enctype!)
```html
<form method="post" enctype="multipart/form-data">
    {% csrf_token %}
    {{ form.as_p }}
    <button type="submit">Завантажити</button>
</form>
```

## 4. Валідація файлів

```python
from django.core.exceptions import ValidationError

def validate_file_size(value):
    limit = 5 * 1024 * 1024  # 5MB
    if value.size > limit:
        raise ValidationError(f'Файл занадто великий. Максимум 5MB')

def validate_image_extension(value):
    import os
    ext = os.path.splitext(value.name)[1]
    valid_extensions = ['.jpg', '.jpeg', '.png', '.gif']
    if ext.lower() not in valid_extensions:
        raise ValidationError('Тільки JPG, PNG та GIF файли')
```

```python
class Document(models.Model):
    file = models.FileField(
        upload_to='documents/',
        validators=[validate_file_size, validate_image_extension]
    )
```

## 5. Робота із зображеннями (Pillow)

Встановіть: `pip install Pillow`

```python
from io import BytesIO
from PIL import Image
from django.core.files.base import ContentFile
from django.db import models

class Profile(models.Model):
    avatar = models.ImageField(upload_to='avatars/', blank=True)

    def save(self, *args, **kwargs):
        if self.avatar:
            img = Image.open(self.avatar)
            # Зміна розміру
            if img.height > 300 or img.width > 300:
                output_size = (300, 300)
                img.thumbnail(output_size)
                # Збереження
                thumb_io = BytesIO()
                img.save(thumb_io, format='JPEG', quality=85)
                self.avatar.save(
                    self.avatar.name,
                    ContentFile(thumb_io.getvalue()),
                    save=False
                )
        super().save(*args, **kwargs)
```


## 8. Кастомні storage

### Збереження в S3 (boto3)
```python
# settings.py
DEFAULT_FILE_STORAGE = 'storages.backends.s3boto3.S3Boto3Storage'
AWS_ACCESS_KEY_ID = 'your-access-key'
AWS_SECRET_ACCESS_KEY = 'your-secret-key'
AWS_STORAGE_BUCKET_NAME = 'my-bucket'

```

```python
# Кастомний storage
from django.core.files.storage import FileSystemStorage
from django.conf import settings
import os

class OverwriteStorage(FileSystemStorage):
    def get_available_name(self, name, max_length=None):
        if self.exists(name):
            self.delete(name)
        return name
```
