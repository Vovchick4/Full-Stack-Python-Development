## 1. Django Forms

Форми в Django відповідають за:
1. Відображення HTML-форми
2. Валідацію даних
3. Перетворення даних у Python-об'єкти

### Створення форми
```python
# blog/forms.py
from django import forms
from .models import Post

class ContactForm(forms.Form):
    name = forms.CharField(max_length=100, label="Ваше ім'я")
    email = forms.EmailField(label="Email")
    message = forms.CharField(widget=forms.Textarea, label="Повідомлення")
    agree = forms.BooleanField(label="Я згоден з умовами")
```

### Форма на основі моделі (ModelForm)
```python
class PostForm(forms.ModelForm):
    class Meta:
        model = Post
        fields = ['title', 'content', 'category', 'tags']
        widgets = {
            'content': forms.Textarea(attrs={'rows': 5}),
            'tags': forms.CheckboxSelectMultiple(),
        }
        labels = {
            'title': 'Заголовок',
            'content': 'Текст посту',
        }
        help_texts = {
            'title': 'Максимум 200 символів',
        }
```

## 2. Типи полів та віджети

| Поле форми | Віджет | HTML |
|-----------|--------|------|
| `CharField` | `TextInput` | `<input type="text">` |
| `EmailField` | `EmailInput` | `<input type="email">` |
| `IntegerField` | `NumberInput` | `<input type="number">` |
| `BooleanField` | `CheckboxInput` | `<input type="checkbox">` |
| `ChoiceField` | `Select` | `<select>` |
| `MultipleChoiceField` | `SelectMultiple` | `<select multiple>` |
| `DateField` | `DateInput` | `<input type="date">` |
| `FileField` | `ClearableFileInput` | `<input type="file">` |

## 3. Відображення форми в шаблоні

### У view:
```python
from django.shortcuts import render, redirect
from .forms import ContactForm

def contact_view(request):
    if request.method == 'POST':
        form = ContactForm(request.POST)
        if form.is_valid():
            # Дані валідні, form.cleaned_data містить чисті дані
            name = form.cleaned_data['name']
            email = form.cleaned_data['email']
            message = form.cleaned_data['message']
            # Тут можна відправити email або зберегти в БД
            return redirect('success')
    else:
        form = ContactForm()

    return render(request, 'contact.html', {'form': form})
```

### У шаблоні:
```html
<form method="post" enctype="multipart/form-data">
    {% csrf_token %}

    {{ form.as_p }}     <!-- як <p> теги -->
    {{ form.as_ul }}    <!-- як <li> теги -->
    {{ form.as_table }} <!-- як <tr> теги -->

    <!-- Ручне виведення -->
    <div>
        {{ form.name.label_tag }}
        {{ form.name }}
        {{ form.name.errors }}
    </div>

    <button type="submit">Відправити</button>
</form>
```

## 4. Валідація даних

### Вбудовані валідатори:
```python
from django.core.validators import MinValueValidator, MaxValueValidator, EmailValidator, RegexValidator

class ProductForm(forms.Form):
    price = forms.DecimalField(
        validators=[MinValueValidator(0.01), MaxValueValidator(99999)]
    )
    phone = forms.CharField(
        validators=[RegexValidator(r'^\+?380\d{9}$', 'Невірний формат телефону')]
    )
```

### Кастомна валідація:
```python
class PostForm(forms.ModelForm):
    class Meta:
        model = Post
        fields = '__all__'

    # Валідація конкретного поля
    def clean_title(self):
        title = self.cleaned_data.get('title')
        if 'погане_слово' in title.lower():
            raise forms.ValidationError("Заголовок містить заборонені слова!")
        return title

    # Валідація всієї форми
    def clean(self):
        cleaned_data = super().clean()
        title = cleaned_data.get('title')
        content = cleaned_data.get('content')
        if title and content and title in content:
            raise forms.ValidationError("Заголовок не має бути в тексті!")
        return cleaned_data
```

## 5. CSRF захист

Django автоматично захищає від CSRF-атак. У кожній формі потрібно додавати:

```html
<form method="post">
    {% csrf_token %}
    ...
</form>
```

Для AJAX запитів:
```html
<script>
fetch('/api/', {
    method: 'POST',
    headers: {
        'X-CSRFToken': '{{ csrf_token }}',
    },
    body: JSON.stringify(data)
})
</script>
```

## 6. Обробка файлів через форму

```python
class AvatarForm(forms.Form):
    avatar = forms.ImageField(label="Фото профілю")
```

```python
def upload_avatar(request):
    if request.method == 'POST':
        form = AvatarForm(request.POST, request.FILES)
        if form.is_valid():
            # Збереження файлу
            handle_uploaded_file(request.FILES['avatar'])
            return redirect('success')
    else:
        form = AvatarForm()
    return render(request, 'upload.html', {'form': form})

def handle_uploaded_file(f):
    with open(f'uploads/{f.name}', 'wb+') as destination:
        for chunk in f.chunks():
            destination.write(chunk)
```
