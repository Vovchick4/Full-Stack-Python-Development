## Домашнє завдання: Форми та валідація

### Завдання 1. Форма зворотного зв'язку
Створіть форму `FeedbackForm` з полями:
- `name` (CharField, max_length=100)
- `email` (EmailField)
- `rating` (ChoiceField: 1-5)
- `message` (CharField, widget=Textarea)
- `subscribe` (BooleanField, label="Підписатися на новини")

### Завдання 2. ModelForm для Post
Створіть `PostModelForm` на основі моделі Post:
- Додайте кастомну валідацію: title не може починатися з цифри
- Додайте кастомний clean(): content не може бути коротшим за 10 символів
- Використайте кастомні віджети для полів

### Завдання 3. HTML-шаблон
Створіть шаблон для форми з:
- Відображенням помилок біля кожного поля
- CSS класами для Bootstrap (або власними стилями)
- CSRF токеном
- Кнопкою "Відправити"

### Завдання 4 (⭐ Зірочка). AJAX форма
Створіть форму, яка:
- Відправляється через fetch (JavaScript)
- Показує помилки валідації без перезавантаження сторінки
- Використовує `JsonResponse` на стороні сервера

### Критерії прийому:
- Форми проходять валідацію
- Помилки відображаються коректно
- CSRF захист працює
- ModelForm створює та редагує об'єкти
