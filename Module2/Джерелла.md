# Ресурси для вивчення Django: Від основ до профі

Цей список містить найкращі покрокові інструкції та відеоуроки для початківців, які допоможуть швидко освоїти Django, особливо після досвіду з FastAPI.

---

## 1. Офіційний туторіал Django (Версія 6.0)

Це першоджерело, яке обов'язкове для ознайомлення. Ви навчитеся створювати додаток для опитувань (Polls App), працювати з базою даних та адмін-панеллю.

- **Тип:** Текстовий посібник (Документація)
- **Рівень:** Початковий
- **Посилання:** [Writing your first Django app, part 1](https://docs.djangoproject.com/en/6.0/intro/tutorial01/)
- **Ключові теми:** Моделі (ORM), URL-адреси, Представлення (Views), Шаблони (Templates).

## 2. Django Girls Tutorial (Українською)

Один із найпопулярніших у світі туторіалів для тих, хто тільки починає свій шлях. Все пояснюється максимально доступно.

- **Тип:** Інтерактивний підручник
- **Рівень:** Абсолютний новачок
- **Посилання:** [Посібник Django Girls (UKR)](https://tutorial.djangogirls.org/uk/)
- **Особливість:** Веде від встановлення Python до розгортання (деплою) готового блогу в інтернеті.

## 3. MDN Web Docs: Django Tutorial

Глибокий та структурований курс від розробників Mozilla. Ідеально підходить для розуміння архітектури.

- **Тип:** Навчальна програма
- **Рівень:** Середній / Систематизація знань
- **Посилання:** [MDN Django Web Framework (Python)](https://developer.mozilla.org/en-US/docs/Learn/Server-side/Django)
- **Ключові теми:** Безпека, автентифікація, робота з формами та тестування.

## 4. Відеокурс: Django 5 (YouTube)

Повний відеокурс для тих, хто краще сприймає інформацію візуально. Актуальна версія фреймворку.

- **Тип:** Відеосерія
- **Автор:** self.edu (Сергій Балакірєв)
- **Посилання:** [Django 5 уроки (YouTube Playlist)](https://www.youtube.com/watch?v=d0mwWMmG7cQ&list=PL7vq4D0vOpQYwMCRuk-sSAnNT5zhrKsLs)
- **Особливість:** Детальне розжовування кожної деталі, від маршрутизації до роботи з класовими представленнями (CBV).

## Порада для розробників FastAPI:

Переходячи на Django, зверніть увагу на наступні відмінності:

1.  **Django ORM:** Вам не потрібні Pydantic або SQLAlchemy, Django має вбудований потужний інструмент для роботи з БД.
2.  **Структура:** Django вимагає суворого розподілу на проєкт (Project) та додатки (Apps).
3.  **Admin:** Не забудьте зареєструвати свої моделі в `admin.py`, щоб отримати готову панель керування автоматично.
