## Домашнє завдання: Тестування, безпека та деплой

### Завдання 1. Тестування моделей
Напишіть тести для моделей `Product` та `Category`:
1. Тест створення об'єкта
2. Тест `__str__` методу
3. Тест валідації полів
4. Тест зв'язків (ForeignKey, ManyToMany)
5. Тест кастомних методів

### Завдання 2. Тестування views
Напишіть тести для:
1. `ProductListView` — статус 200, правильний шаблон, контекст
2. `ProductDetailView` — статус 200, 404 для неіснуючого товару
3. `ProductCreateView` — доступ тільки авторизованим
4. `ProductUpdateView` — доступ тільки автору
5. API endpoint — всі CRUD операції

### Завдання 3. Налаштування безпеки
1. Додайте HTTPS налаштування в `settings.py`
2. Налаштуйте змінні середовища через `.env`
3. Додайте заголовки безпеки (CSP, X-Frame-Options)
4. Перевірте безпеку через `python manage.py check --deploy`

### Завдання 4 (⭐ Зірочка). Docker деплой
1. Створіть `Dockerfile` для Django проекту
2. Створіть `docker-compose.yml` з PostgreSQL
3. Налаштуйте Gunicorn замість development сервера
4. Додайте `collectstatic` в Dockerfile

### Критерії прийому:
- Всі тести проходять успішно
- Покриття тестів не менше 80%
- Налаштування безпеки відповідають рекомендаціям Django
- Docker контейнери запускаються без помилок
