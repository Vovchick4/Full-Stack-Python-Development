## 1. Тестування в Django

Django базується на Python's `unittest` і надає розширені інструменти для тестування.

### Види тестів:
- **Unit тести** — тестування окремих компонентів
- **Integration тести** — тестування взаємодії компонентів
- **Functional тести** — тестування через браузер (Selenium)

```bash
# Запуск тестів
python manage.py test

# Запуск конкретного додатку
python manage.py test blog

# Запуск конкретного тесту
python manage.py test blog.tests.PostModelTest

# З coverage
pip install coverage
coverage run --source='.' manage.py test
coverage report
coverage html
```

## 2. Тестування моделей

```python
# blog/tests.py
from django.test import TestCase
from django.contrib.auth.models import User
from .models import Post, Category

class PostModelTest(TestCase):
    @classmethod
    def setUpTestData(cls):
        """Створення даних для тестів (один раз для всього класу)"""
        cls.user = User.objects.create_user(username='testuser', password='12345')
        cls.category = Category.objects.create(name='Python')
        cls.post = Post.objects.create(
            title='Test Post',
            content='Test content',
            author=cls.user,
            category=cls.category
        )

    def test_post_creation(self):
        self.assertEqual(Post.objects.count(), 1)

    def test_post_str_method(self):
        self.assertEqual(str(self.post), 'Test Post')

    def test_post_absolute_url(self):
        self.assertEqual(self.post.get_absolute_url(), f'/blog/post/{self.post.pk}/')

    def test_default_is_published(self):
        self.assertFalse(self.post.is_published)

    def test_title_max_length(self):
        max_length = self.post._meta.get_field('title').max_length
        self.assertEqual(max_length, 200)
```

## 3. Тестування views

### Тестування FBV/CBV
```python
from django.test import TestCase, Client
from django.urls import reverse

class PostViewTest(TestCase):
    def setUp(self):
        self.client = Client()
        self.user = User.objects.create_user(username='testuser', password='12345')
        self.post = Post.objects.create(
            title='Test Post',
            content='Test content',
            author=self.user
        )

    def test_post_list_view(self):
        url = reverse('blog:list')
        response = self.client.get(url)
        self.assertEqual(response.status_code, 200)
        self.assertTemplateUsed(response, 'blog/post_list.html')
        self.assertContains(response, 'Test Post')

    def test_post_detail_view(self):
        url = reverse('blog:detail', args=[self.post.pk])
        response = self.client.get(url)
        self.assertEqual(response.status_code, 200)
        self.assertContains(response, 'Test content')

    def test_post_create_view_authenticated(self):
        self.client.login(username='testuser', password='12345')
        url = reverse('blog:create')
        response = self.client.get(url)
        self.assertEqual(response.status_code, 200)

    def test_post_create_view_unauthenticated(self):
        url = reverse('blog:create')
        response = self.client.get(url)
        self.assertRedirects(response, f'/login/?next={url}')

    def test_post_create(self):
        self.client.login(username='testuser', password='12345')
        url = reverse('blog:create')
        response = self.client.post(url, {
            'title': 'New Post',
            'content': 'New content',
            'category': self.category.pk,
        })
        self.assertEqual(Post.objects.count(), 2)
        self.assertRedirects(response, reverse('blog:list'))
```

### Тестування API (DRF)
```python
from rest_framework import status
from rest_framework.test import APITestCase, APIClient

class PostAPITest(APITestCase):
    def setUp(self):
        self.client = APIClient()
        self.user = User.objects.create_user(username='testuser', password='12345')
        self.post = Post.objects.create(title='Test', content='Content', author=self.user)

    def test_list_posts(self):
        url = '/api/posts/'
        response = self.client.get(url)
        self.assertEqual(response.status_code, status.HTTP_200_OK)
        self.assertEqual(len(response.data['results']), 1)

    def test_create_post_authenticated(self):
        self.client.force_authenticate(user=self.user)
        url = '/api/posts/'
        data = {'title': 'API Post', 'content': 'API Content'}
        response = self.client.post(url, data, format='json')
        self.assertEqual(response.status_code, status.HTTP_201_CREATED)
        self.assertEqual(Post.objects.count(), 2)

    def test_create_post_unauthenticated(self):
        url = '/api/posts/'
        data = {'title': 'API Post', 'content': 'API Content'}
        response = self.client.post(url, data, format='json')
        self.assertEqual(response.status_code, status.HTTP_401_UNAUTHORIZED)
```

## 4. Безпека в Django

### Захист від CSRF
```html
<form method="post">
    {% csrf_token %}
    ...
</form>
```

### XSS захист
Django автоматично екранує HTML у шаблонах:
```html
{{ user_input }}  <!-- <script> -> &lt;script&gt; -->
{{ user_input|safe }}  <!-- без екранування (обережно!) -->
```

### SQL-ін'єкції
Django ORM автоматично захищає:
```python
# Безпечно:
Post.objects.filter(title=user_input)

# НЕБЕЗПЕЧНО (ніколи так не робіть):
from django.db import connection
cursor.execute(f"SELECT * FROM post WHERE title = '{user_input}'")
```

## 5. Деплой Django

### Середовище та змінні
```python
# .env
SECRET_KEY=your-secret-key
DEBUG=False
DATABASE_URL=postgres://user:password@localhost:5432/dbname
ALLOWED_HOSTS=example.com,www.example.com
```

```python
# settings.py
import os
from dotenv import load_dotenv

load_dotenv()

SECRET_KEY = os.getenv('SECRET_KEY')
DEBUG = os.getenv('DEBUG') == 'True'
ALLOWED_HOSTS = os.getenv('ALLOWED_HOSTS').split(',')
```

### Gunicorn + Nginx
```bash
pip install gunicorn
gunicorn mysite.wsgi:application --bind 0.0.0.0:8000 --workers 4
```

```nginx
# /etc/nginx/sites-available/mysite
server {
    listen 80;
    server_name example.com;

    location /static/ {
        alias /path/to/staticfiles/;
    }

    location /media/ {
        alias /path/to/media/;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### Docker
