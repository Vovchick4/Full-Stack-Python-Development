## Домашнє завдання: Моделі та ORM

### Завдання 1. Створення моделей
Створіть модель `Book` з полями:
- `title` (CharField, max_length=200)
- `author` (CharField, max_length=100)
- `description` (TextField)
- `price` (DecimalField, max_digits=6, decimal_places=2)
- `published_date` (DateField)
- `is_available` (BooleanField, default=True)
- `created_at` (DateTimeField, auto_now_add=True)

### Завдання 2. Зв'язки
Створіть моделі `Author` та `Book` з ForeignKey зв'язком:
- `Author` має поля: `name`, `bio`, `birth_date`
- `Book` має ForeignKey на `Author` з `related_name='books'`
- Додайте модель `Genre` з ManyToMany зв'язком до `Book`

### Завдання 3. Робота з ORM (у Python shell)
1. Створіть 3 авторів та 5 книг
2. Знайдіть всі книги конкретного автора
3. Знайдіть всі книги, ціна яких більше 100 грн
4. Оновіть ціну книги на 150 грн
5. Видаліть книгу з ID = 2
6. Порахуйте кількість книг кожного автора

### Завдання 4. Кастомний менеджер
Створіть менеджер `AvailableManager`, який фільтрує тільки доступні книги (`is_available=True`).

### Критерії прийому:
- Всі моделі створено з правильними типами полів
- Створено та застосовано міграції
- Всі ORM запити працюють коректно
- Додано `__str__` методи для всіх моделей
