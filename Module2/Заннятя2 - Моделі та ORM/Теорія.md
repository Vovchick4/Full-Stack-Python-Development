## 1. Що таке ORM?

**ORM (Object-Relational Mapping)** — це технологія, яка дозволяє працювати з базою даних через об'єкти Python, не пишучи SQL-запити.

Django ORM підтримує: SQLite, PostgreSQL, MySQL, Oracle.

---

## 2. Створення моделей

Модель — це Python-клас, який відображає таблицю в БД.

```python
# blog/models.py
from django.db import models

class Post(models.Model):
    title = models.CharField(max_length=200)
    content = models.TextField()
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)
    is_published = models.BooleanField(default=False)

    def __str__(self):
        return self.title
```

### Основні типи полів:
| Поле | Опис |
|------|------|
| `CharField(max_length=N)` | Текст до N символів |
| `TextField()` | Великий текст |
| `IntegerField()` | Ціле число |
| `FloatField()` | Число з плавоючою крапкою |
| `BooleanField()` | Так/Ні |
| `DateTimeField()` | Дата та час |
| `DateField()` | Дата |
| `EmailField()` | Email |
| `URLField()` | URL-адреса |
| `FileField()` | Файл |
| `ImageField()` | Зображення |

## 3. Міграції

Міграції — це спосіб синхронізації моделей з базою даних.

```bash
# Створити міграції
python manage.py makemigrations

# Застосувати міграції
python manage.py migrate

# Подивитися SQL-запит міграції
python manage.py sqlmigrate blog 0001
```

## 4. CRUD операції через ORM

### CREATE (Створення)
```python
# Спосіб 1
post = Post(title="Мій перший пост", content="Текст посту")
post.save()

# Спосіб 2
Post.objects.create(title="Другий пост", content="Ще текст")
```

### READ (Читання)
```python
# Всі записи
Post.objects.all()

# Один запис за ID
Post.objects.get(id=1)

# Фільтрація
Post.objects.filter(is_published=True)
Post.objects.filter(title__contains="Python")
Post.objects.exclude(is_published=True)

# Сортування
Post.objects.order_by('-created_at')  # за спаданням
Post.objects.order_by('created_at')    # за зростанням

# Обмеження
Post.objects.all()[:5]  # перші 5
```

### UPDATE (Оновлення)
```python
post = Post.objects.get(id=1)
post.title = "Новий заголовок"
post.save()

# Масове оновлення
Post.objects.filter(is_published=False).update(is_published=True)
```

### DELETE (Видалення)
```python
post = Post.objects.get(id=1)
post.delete()

# Масове видалення
Post.objects.filter(is_published=False).delete()
```

## 5. Зв'язки між моделями

### One-to-Many (ForeignKey)
```python
class Category(models.Model):
    name = models.CharField(max_length=100)

class Post(models.Model):
    category = models.ForeignKey(Category, on_delete=models.CASCADE, related_name='posts')
```

### Many-to-Many
```python
class Tag(models.Model):
    name = models.CharField(max_length=50)

class Post(models.Model):
    tags = models.ManyToManyField(Tag, related_name='posts')
```

### One-to-One
```python
class Profile(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE)
    bio = models.TextField()
```

## 6. QuerySet методи

```python
# Агрегація
from django.db.models import Count, Sum, Avg

Post.objects.aggregate(Count('id'))
Post.objects.aggregate(Sum('views'))

# Group by
Post.objects.values('category__name').annotate(count=Count('id'))

# Складні фільтри
from django.db.models import Q

Post.objects.filter(Q(title__contains="Python") | Q(content__contains="Python"))
Post.objects.filter(Q(is_published=True) & Q(created_at__year=2024))
```

## 7. Менеджери (Custom Managers)

```python
class PublishedManager(models.Manager):
    def get_queryset(self):
        return super().get_queryset().filter(is_published=True)

class Post(models.Model):
    objects = models.Manager()  # стандартний
    published = PublishedManager()  # кастомний

# Використання
Post.published.all()
```
