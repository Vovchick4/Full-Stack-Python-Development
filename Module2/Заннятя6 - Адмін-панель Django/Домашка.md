## Домашнє завдання: Адмін-панель Django

### Завдання 1. Реєстрація моделей
Створіть моделі `Product`, `Category`, `Order` та зареєструйте їх в адмін-панелі:
- `Product`: name, price, category, stock, is_active, created_at
- `Category`: name, slug, description
- `Order`: user, products (ManyToMany), total_price, status, created_at

### Завдання 2. Кастомізація ProductAdmin
Налаштуйте `ProductAdmin`:
- `list_display`: name, price, category, stock, is_active
- `list_filter`: category, is_active
- `search_fields`: name, category__name
- `list_editable`: price, stock, is_active
- `date_hierarchy`: created_at
- `ordering`: -created_at

### Завдання 3. Inline та Actions
1. Додайте Inline для Order (TabularInline)
2. Створіть action "Активувати" та "Деактивувати" для Product
3. Додайте action "Позначити як виконано" для Order

### Завдання 4. Кастомізація інтерфейсу
1. Змініть заголовки адмін-панелі
2. Додайте `fieldsets` для Product
3. Використайте `prepopulated_fields` для slug категорії
4. Додайте кастомну адмін-сторінку зі статистикою

### Критерії прийому:
- Всі моделі зареєстровані та працюють
- Фільтри, пошук та сортування функціонують
- Actions виконують масові операції
- Inline відображають пов'язані моделі
