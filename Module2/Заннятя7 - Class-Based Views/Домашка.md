## Домашнє завдання: Class-Based Views

### Завдання 1. TemplateView
Створіть `HomePageView` (TemplateView) для головної сторінки, яка показує:
- Останні 5 постів
- Список категорій
- Кількість користувачів

### Завдання 2. ListView + DetailView
Створіть для моделі `Product`:
1. `ProductListView` — з пагінацією (12 товарів на сторінку), фільтрацією за категорією
2. `ProductDetailView` — показує товар, схожі товари (та ж категорія)
3. Додайте можливість сортування за ціною та назвою

### Завдання 3. CreateView + UpdateView + DeleteView
Створіть для `Product`:
1. `ProductCreateView` — з ModelForm, автозаповненням автора
2. `ProductUpdateView` — з перевіркою прав (тільки автор може редагувати)
3. `ProductDeleteView` — з підтвердженням видалення

### Завдання 4. Міксини
1. Створіть міксин `OwnerRequiredMixin`, який перевіряє, чи користувач є власником об'єкта
2. Застосуйте його до UpdateView та DeleteView
3. Додайте `LoginRequiredMixin` до CreateView

### Критерії прийому:
- Всі CBV працюють коректно
- Пагінація та фільтрація реалізовані
- Міксини перевіряють права доступу
- Шаблони використовують наслідування
