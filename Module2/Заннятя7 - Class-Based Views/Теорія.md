## 1. Що таке Class-Based Views (CBV)?

CBV — це представлення у вигляді класів замість функцій. Вони дозволяють перевикористовувати код за допомогою наслідування та міксинів.

### Переваги CBV:
- Перевикористання коду
- Вбудовані загальні представлення (ListView, DetailView, тощо)
- Зручне розширення через міксини

```python
from django.views import View
from django.http import HttpResponse

class MyView(View):
    def get(self, request):
        return HttpResponse("Hello from CBV!")

    def post(self, request):
        return HttpResponse("POST request handled!")
```

## 2. Базові CBV

### View
```python
from django.views import View
from django.shortcuts import render, redirect
from .forms import ContactForm

class ContactView(View):
    template_name = 'contact.html'

    def get(self, request):
        form = ContactForm()
        return render(request, self.template_name, {'form': form})

    def post(self, request):
        form = ContactForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect('success')
        return render(request, self.template_name, {'form': form})
```

### TemplateView
```python
from django.views.generic import TemplateView

class AboutView(TemplateView):
    template_name = 'about.html'

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context['company_name'] = 'My Company'
        context['year'] = 2026
        return context
```

### RedirectView
```python
from django.views.generic import RedirectView

class BlogRedirectView(RedirectView):
    url = '/blog/'
    permanent = True  # 301 редирект

class ExternalRedirectView(RedirectView):
    pattern_name = 'blog:home'  # редирект за іменем URL
    query_string = True
```

## 3. Generic Display Views

### ListView
```python
from django.views.generic import ListView
from .models import Post

class PostListView(ListView):
    model = Post
    template_name = 'blog/post_list.html'  # за замовч.: blog/post_list.html
    context_object_name = 'posts'           # за замовч.: object_list
    paginate_by = 10
    ordering = ['-created_at']

    # Фільтрація
    def get_queryset(self):
        return Post.objects.filter(is_published=True)

    # Додаткові дані в контекст
    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context['categories'] = Category.objects.all()
        context['is_paginated'] = self.request.GET.get('page') is not None
        return context
```

### DetailView
```python
from django.views.generic import DetailView

class PostDetailView(DetailView):
    model = Post
    template_name = 'blog/post_detail.html'
    context_object_name = 'post'

    # Збільшення лічильника переглядів
    def get_object(self):
        obj = super().get_object()
        obj.view_count += 1
        obj.save(update_fields=['view_count'])
        return obj

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context['comments'] = self.object.comments.filter(is_moderated=True)
        return context
```

## 4. Generic Edit Views

### CreateView
```python
from django.views.generic import CreateView
from django.urls import reverse_lazy
from .models import Post
from .forms import PostForm

class PostCreateView(CreateView):
    model = Post
    form_class = PostForm
    template_name = 'blog/post_form.html'
    success_url = reverse_lazy('blog:list')

    # Автоматичне встановлення автора
    def form_valid(self, form):
        form.instance.author = self.request.user
        return super().form_valid(form)
```

### UpdateView
```python
class PostUpdateView(UpdateView):
    model = Post
    form_class = PostForm
    template_name = 'blog/post_form.html'

    def get_success_url(self):
        return reverse_lazy('blog:detail', kwargs={'pk': self.object.pk})

    # Перевірка прав
    def dispatch(self, request, *args, **kwargs):
        obj = self.get_object()
        if obj.author != request.user:
            return redirect('blog:list')
        return super().dispatch(request, *args, **kwargs)
```

### DeleteView
```python
from django.views.generic import DeleteView
from django.contrib.auth.mixins import LoginRequiredMixin

class PostDeleteView(LoginRequiredMixin, DeleteView):
    model = Post
    template_name = 'blog/post_confirm_delete.html'
    success_url = reverse_lazy('blog:list')
    login_url = '/login/'
```

## 5. Форми в CBV

```python
class PostCreateView(CreateView):
    model = Post
    fields = ['title', 'content', 'category', 'tags']
    # або form_class = PostForm

    def get_form(self, form_class=None):
        form = super().get_form(form_class)
        # Кастомізація форми
        form.fields['title'].widget.attrs.update({
            'class': 'form-control',
            'placeholder': 'Введіть заголовок'
        })
        return form

    def form_invalid(self, form):
        # Логування помилок
        print(form.errors)
        return super().form_invalid(form)
```

## 6. Міксини (Mixins)

Міксини — це класи, які додають функціональність через множинне наслідування.

### Авторизація
```python
from django.contrib.auth.mixins import LoginRequiredMixin, PermissionRequiredMixin

class PostCreateView(LoginRequiredMixin, CreateView):
    login_url = '/login/'
    redirect_field_name = 'next'

class PostApproveView(PermissionRequiredMixin, UpdateView):
    permission_required = 'blog.can_approve'
    # або список: ['blog.can_approve', 'blog.can_publish']
```

### Кастомний міксин
```python
class AuthorRequiredMixin:
    """Перевіряє, чи є поточний користувач автором об'єкта"""
    def dispatch(self, request, *args, **kwargs):
        obj = self.get_object()
        if obj.author != request.user and not request.user.is_staff:
            return redirect('blog:list')
        return super().dispatch(request, *args, **kwargs)

class PostUpdateView(AuthorRequiredMixin, UpdateView):
    model = Post
    fields = ['title', 'content']
```

## 7. Порівняння FBV та CBV

| Завдання | FBV | CBV |
|----------|-----|-----|
| Проста сторінка | `def about(request):` | `TemplateView` |
| Список об'єктів | `def list(request):` | `ListView` |
| Деталі об'єкта | `def detail(request, pk):` | `DetailView` |
| GET/POST обробка | `if request.method ==` | `View.get()` / `View.post()` |
| Форма створення | `if request.POST: form = Form(request.POST)` | `CreateView` |
| Редагування | `get_object_or_404` + форма | `UpdateView` |
| Видалення | POST + `get_object_or_404` + `delete()` | `DeleteView` |
