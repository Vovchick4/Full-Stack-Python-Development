## Домашнє завдання: Створення першого Django проекту

### Завдання 1. Встановлення та налаштування
1. Встановіть Django через `pip install django`
2. Створіть проект з назвою `my_blog`
3. Створіть додаток `posts`
4. Підключіть додаток у `settings.py`
5. Запустіть сервер та переконайтеся, що все працює

### Завдання 2. Створення маршрутів
1. Створіть головну сторінку (`/`), яка повертає "Вітаємо на головній сторінці!"
2. Створіть сторінку `about/`, яка повертає "Про нас"
3. Створіть динамічний маршрут `page/<str:page_name>/`, який повертає текст залежно від назви сторінки

### Завдання 3. Робота з URL
1. Використайте функцію `reverse()` у Python shell для отримання URL за назвою маршруту
2. Додайте `app_name = 'posts'` у файл `urls.py` додатку
3. Використайте простір імен у шаблоні

### Критерії прийому:
- Проект запускається без помилок
- Всі сторінки доступні за вказаними URL
- Код відформатовано згідно PEP 8
- Файли мають чітку структуру
