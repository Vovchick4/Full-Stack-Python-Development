## 1. Що таке Django?

Django — це високорівневий Python веб-фреймворк, який дозволяє швидко створювати безпечні та підтримувані веб-сайти. Створений у 2005 році, він слідує принципу **"Don't Repeat Yourself" (DRY)** та шаблону **MTV (Model-Template-View)**.

### Чому Django?
- **Вбудована адмін-панель** — автоматичний інтерфейс для керування даними
- **ORM** — працюйте з БД без SQL
- **Безпека** — захист від SQL-ін'єкцій, XSS, CSRF тощо
- **Масштабованість** — використовується Instagram, Pinterest, Spotify

---

## 2. Встановлення та створення проекту

```bash
pip install django
django-admin startproject mysite
cd mysite
python manage.py runserver
```

Після запуску перейдіть на `http://127.0.0.1:8000/` — ви побачите вітальну сторінку Django.

### Структура проекту:
```
mysite/
├── manage.py          # Утиліта для керування проектом
├── mysite/
│   ├── __init__.py
│   ├── settings.py    # Налаштування проекту
│   ├── urls.py        # Головний файл маршрутизації
│   ├── asgi.py
│   └── wsgi.py
└── db.sqlite3         # База даних (SQLite за замовчуванням)
```

## 3. Створення додатку (App)

Django проєкт складається з додатків. Кожен додаток — це окремий модуль.

```bash
python manage.py startapp blog
```

Структура додатку:
```
blog/
├── migrations/
├── __init__.py
├── admin.py       # Реєстрація моделей в адмінці
├── apps.py        # Конфігурація додатку
├── models.py      # Моделі бази даних
├── tests.py       # Тести
└── views.py       # Представлення (логіка)
```

---

## 4. Підключення додатку до проекту

У `mysite/settings.py` додайте `'blog'` до списку `INSTALLED_APPS`:

```python
INSTALLED_APPS = [
    'django.contrib.admin',
    'django.contrib.auth',
    'django.contrib.contenttypes',
    'django.contrib.sessions',
    'django.contrib.messages',
    'django.contrib.staticfiles',
    'blog',  # наш додаток
]
```

## 5. Перша View (Функція-представлення)

У `blog/views.py`:

```python
from django.http import HttpResponse

def index(request):
    return HttpResponse("Привіт, світ! Це мій перший Django додаток.")
```

Створіть `blog/urls.py`:

```python
from django.urls import path
from . import views

urlpatterns = [
    path('', views.index, name='index'),
]
```

Підключіть його в головному `mysite/urls.py`:

```python
from django.contrib import admin
from django.urls import include, path

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('blog.urls')),
]
```

## 6. Маршрутизація (URL patterns)

Динамічні URL:

```python
# blog/urls.py
urlpatterns = [
    path('', views.index, name='index'),
    path('post/<int:post_id>/', views.post_detail, name='post_detail'),
]
```

```python
# blog/views.py
def post_detail(request, post_id):
    return HttpResponse(f"Це пост з ID: {post_id}")
```

## 7. Налаштування бази даних

За замовчуванням Django використовує SQLite. Для PostgreSQL у `settings.py`:

```python
DATABASES = {
    'default': {
        'ENGINE': 'django.db.backends.postgresql',
        'NAME': 'mydb',
        'USER': 'myuser',
        'PASSWORD': 'mypassword',
        'HOST': 'localhost',
        'PORT': '5432',
    }
}
```

Застосуйте міграції:
```bash
python manage.py migrate
```
