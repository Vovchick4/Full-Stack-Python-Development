## Домашнє завдання: Django REST Framework

### Завдання 1. Базовий API
Створіть API для моделі `Product`:
1. Встановіть DRF та підключіть його
2. Створіть `ProductSerializer` (ModelSerializer)
3. Створіть `ProductViewSet` з CRUD операціями
4. Зареєструйте маршрути через Router

### Завдання 2. Кастомні дії та дозволи
1. Додайте action `@action(detail=True, methods=['patch'])` для зміни ціни товару
2. Додайте action `@action(detail=False)` для отримання товарів зі знижкою
3. Створіть дозвіл `IsSellerOrReadOnly`, який дозволяє редагувати тільки продавцю
4. Додайте аутентифікацію через Token

### Завдання 3. Фільтрація та пошук
1. Додайте пошук за назвою та описом товару
2. Додайте фільтрацію за категорією та ціною
3. Додайте сортування за ціною та датою створення
4. Налаштуйте пагінацію (20 товарів на сторінку)

### Завдання 4. Nested Serializer
1. Створіть `ReviewSerializer` для відгуків на товари
2. Додайте поле `reviews` у `ProductSerializer`
3. Додайте поле `average_rating` (SerializerMethodField)
4. Дозвольте створювати відгуки через API

### Критерії прийому:
- Всі CRUD операції працюють через API
- Аутентифікація та дозволи налаштовані
- Фільтрація, пошук та пагінація працюють
- API документовано (доступний /api/docs/)
