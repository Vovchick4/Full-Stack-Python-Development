## Домашнє завдання: Базові концепції JS

### Завдання 1. Деструктуризація
Дано об'єкт:
```javascript
const product = {
    id: 1,
    title: 'Футболка',
    price: 499,
    sizes: { s: 5, m: 10, l: 3 },
    inStock: true,
};
```
1. Дістаньте title та price через деструктуризацію
2. Дістаньте sizes та з нього — m
3. Перейменуйте title в productName
4. Дістаньте залишок полів у змінну rest

### Завдання 2. Spread/Rest
1. Напишіть функцію `mergeArrays(...arrays)`, яка зливає будь-яку кількість масивів
2. Створіть копію масиву через spread та додайте туди новий елемент
3. Створіть новий об'єкт на основі user, додавши нове поле та змінивши існуюче

### Завдання 3. Async/Await
Використайте `https://jsonplaceholder.typicode.com/posts`:
1. Напишіть async функцію `getPost(id)`, яка завантажує один пост
2. Напишіть async функцію `getAllPosts()`, яка завантажує всі пости
3. Виведіть заголовки всіх постів у консоль
4. Додайте обробку помилок (try/catch)

### Завдання 4. Методи масивів
Масив товарів:
```javascript
const products = [
    { name: 'Ноутбук', price: 35000, category: 'electronics', rating: 4.5 },
    { name: 'Футболка', price: 499, category: 'clothing', rating: 4.2 },
    { name: 'Телефон', price: 12000, category: 'electronics', rating: 4.8 },
    { name: 'Кросівки', price: 2500, category: 'clothing', rating: 4.0 },
];
```
1. electronics з рейтингом > 4.3 (filter)
2. Назви товарів з ціною з ПДВ (map, price * 1.2)
3. Загальна вартість усіх товарів (reduce)
4. Згрупуйте товари за категоріями (reduce)

### Критерії прийому:
- Всі завдання виконані в одному JS файлі
- Код запускається без помилок
- Використано сучасний синтаксис (ES6+)
- Асинхронний код з try/catch
