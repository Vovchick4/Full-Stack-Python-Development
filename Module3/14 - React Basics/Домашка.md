### Завдання 1
Створіть компонент ProductCard (title, price, image, isNew). Якщо isNew — показувати бейдж "Новинка". Використайте в App з масивом з 3+ товарів. Використайте map.

### Завдання 2
Створіть компонент Counter. Додайте кнопки +5, -5, подвоїти, скинути. Не дайте count стати від'ємним.

### Завдання 3
Створіть компонент Users: завантажує користувачів з API (https://jsonplaceholder.typicode.com/users). Покажіть loader під час завантаження. Обробіть помилку. Додайте пошук (input, фільтрація за name).
