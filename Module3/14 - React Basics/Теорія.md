## 1. Що таке React?

React — JavaScript-бібліотека для створення інтерфейсів. Розроблена Facebook.

### Ключові концепції:
- **Компоненти** — перевикористовувані блоки UI
- **JSX** — HTML-подібний синтаксис в JS
- **Virtual DOM** — швидке оновлення тільки змінених частин
- **State** — внутрішній стан компонента
- **Props** — параметри компонента

## 3. JSX — правила

```jsx
// 1. Один кореневий елемент (або Fragment)
function Comp() {
    return (
        <>
            <h1>Текст</h1>
            <p>Ще текст</p>
        </>
    );
}

// 2. className замість class
<div className="container">

// 3. JS-вирази в {}
<h1>{name.toUpperCase()}</h1>
<h1>{2 + 2}</h1>
<h1>{condition ? 'Так' : 'Ні'}</h1>

// 4. Стилі — об'єкт
<div style={{ color: 'red', fontSize: '20px' }}>

// 5. Події — camelCase
<button onClick={() => alert('Клік')}>Натисни</button>
```

## 4. Компоненти та Props

```jsx
function Card({ title, price, children }) {
    return (
        <div className="card">
            <h2>{title}</h2>
            <span>{price} грн</span>
            {children}
        </div>
    );
}

// Використання
<Card title="Футболка" price={499}>
    <button>Купити</button>
</Card>

// Props за замовчуванням
function Button({ children, variant = 'primary', disabled = false }) {
    return (
        <button className={`btn btn-${variant}`} disabled={disabled}>
            {children}
        </button>
    );
}
```

## 5. State (Стан)

```jsx
import { useState } from 'react';

function Counter() {
    const [count, setCount] = useState(0);

    return (
        <div>
            <p>Лічильник: {count}</p>
            <button onClick={() => setCount(count + 1)}>+</button>
            <button onClick={() => setCount(prev => prev - 1)}>-</button>
            <button onClick={() => setCount(0)}>Скинути</button>
        </div>
    );
}
```

### Правила useState:
- Не змінюйте state напряму — тільки через setter
- Для об'єктів — створюйте новий

```jsx
const [user, setUser] = useState({ name: '', age: 0 });
setUser(prev => ({ ...prev, name: 'Олена' }));
```

## 6. Virtual DOM

React створює "віртуальну" копію DOM в пам'яті. При зміні state:
1. React створює новий Virtual DOM
2. Порівнює з попереднім (diffing)
3. Оновлює тільки змінені частини (reconciliation)

## 7. Умовний рендеринг

```jsx
function Profile({ user }) {
    if (!user) return <p>Увійдіть</p>;

    return (
        <div>
            <h2>{user.name}</h2>
            {user.isAdmin && <p>Панель адміна</p>}
            {user.age >= 18
                ? <p>Доступ дозволено</p>
                : <p>Доступ заборонено</p>
            }
        </div>
    );
}
```

## 8. Списки та ключі

```jsx
function List({ items }) {
    return (
        <ul>
            {items.map(item => (
                <li key={item.id}>{item.name}</li>
            ))}
        </ul>
    );
}

// key = item.id (стабільний), не index
```

## 9. useEffect

```jsx
import { useState, useEffect } from 'react';

function Users() {
    const [users, setUsers] = useState([]);
    const [loading, setLoading] = useState(true);

    useEffect(() => {
        fetch('https://jsonplaceholder.typicode.com/users')
            .then(res => res.json())
            .then(setUsers)
            .finally(() => setLoading(false));
    }, []);  // [] — один раз при монтуванні

    if (loading) return <p>Завантаження...</p>;
    return <ul>{users.map(u => <li key={u.id}>{u.name}</li>)}</ul>;
}
```
