## 1. Flexbox

Flexbox призначений для одновимірного розташування елементів (у рядок або в колонку).

### Flex Container

```css
.container {
    display: flex;
    /* Напрямок */
    flex-direction: row;              /* рядок (за замовч.) */
    flex-direction: column;           /* колонка */
    flex-direction: row-reverse;      /* рядок навпаки */
    flex-direction: column-reverse;   /* колонка навпаки */

    /* Перенос */
    flex-wrap: nowrap;                /* не переносити (за замовч.) */
    flex-wrap: wrap;                  /* переносити */
    flex-wrap: wrap-reverse;          /* переносити навпаки */

    /* Швидкий запис: direction + wrap */
    flex-flow: row wrap;

    /* Вирівнювання по головній осі (горизонтально) */
    justify-content: flex-start;      /* на початок (за замовч.) */
    justify-content: flex-end;        /* в кінець */
    justify-content: center;          /* по центру */
    justify-content: space-between;   /* рівномірно, крайні до країв */
    justify-content: space-around;    /* рівномірно з половиною відступу з країв */
    justify-content: space-evenly;    /* повністю рівномірно */

    /* Вирівнювання по поперечній осі (вертикально) */
    align-items: stretch;             /* розтягнути (за замовч.) */
    align-items: flex-start;          /* вгорі */
    align-items: flex-end;            /* внизу */
    align-items: center;              /* по центру */
    align-items: baseline;            /* по базовій лінії тексту */

    /* Вирівнювання при переносі (багато рядків) */
    align-content: flex-start;        /* зверху */
    align-content: center;            /* по центру */
    align-content: space-between;     /* рівномірно */
}
```

### Flex Items

```css
.item {
    /* Порядок (за замовч. 0) */
    order: 1;
    order: -1;  /* буде першим */

    /* Збільшення (пропорція) */
    flex-grow: 1;    /* займати вільний простір */
    flex-grow: 2;    /* вдвічі більше */

    /* Зменшення */
    flex-shrink: 1;  /* дозволено зменшуватись (за замовч.) */
    flex-shrink: 0;  /* заборонено зменшуватись */

    /* Базова ширина */
    flex-basis: 200px;
    flex-basis: 50%;
    flex-basis: auto;  /* за розміром контенту */

    /* Швидкий запис */
    flex: 1;                    /* flex-grow: 1; flex-shrink: 1; flex-basis: 0 */
    flex: 0 0 200px;            /* не росте, не зменшується, 200px */
    flex: 1 1 300px;            /* може рости і зменшуватись, база 300px */

    /* Самостійне вирівнювання (перекриває align-items) */
    align-self: center;
    align-self: flex-end;
    align-self: stretch;
}
```

## 2. CSS Grid

Grid призначений для двовимірного розташування (рядки + колонки одночасно).

### Grid Container

```css
.grid {
    display: grid;

    /* Колонки */
    grid-template-columns: 200px 1fr 1fr;         /* 3 колонки */
    grid-template-columns: repeat(3, 1fr);         /* 3 рівні колонки */
    grid-template-columns: 1fr 2fr 1fr;            /* пропорції */
    grid-template-columns: 200px auto;             /* фікс + авто */
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)); /* адаптивно */

    /* Рядки */
    grid-template-rows: 100px auto 100px;          /* 3 рядки */
    grid-template-rows: repeat(2, 200px);          /* 2 рядки по 200px */

    /* Відступи */
    gap: 20px;                    /* між рядками і колонками */
    column-gap: 30px;             /* тільки між колонками */
    row-gap: 10px;                /* тільки між рядками */

    /* Вирівнювання */
    justify-items: stretch;       /* по горизонталі (за замовч.) */
    align-items: stretch;         /* по вертикалі (за замовч.) */
    place-items: center;          /* скорочення для justify + align */
}
```

### Grid Items

```css
.header {
    grid-column: 1 / -1;         /* від першої до останньої лінії */
    grid-column: 1 / 3;          /* займає 2 колонки */
    grid-column: span 2;         /* те ж саме */

    grid-row: 1 / 3;             /* займає 2 рядки */
    grid-row: span 2;

    /* Скорочення: grid-row-start / grid-column-start / grid-row-end / grid-column-end */
    grid-area: 1 / 1 / 3 / 3;

    /* Самовирівнювання */
    justify-self: center;
    align-self: end;
}
```

### Приклад: макет сторінки (Holy Grail Layout)

```css
.page {
    display: grid;
    grid-template-columns: 250px 1fr 250px;
    grid-template-rows: 80px 1fr 60px;
    grid-template-areas:
        "header header header"
        "sidebar content aside"
        "footer footer footer";
    min-height: 100vh;
    gap: 0;
}

header  { grid-area: header;  background: #333; color: white; }
.sidebar { grid-area: sidebar; background: #f0f0f0; }
.content { grid-area: content; padding: 20px; }
aside   { grid-area: aside;   background: #f9f9f9; }
footer  { grid-area: footer;  background: #222; color: white; }

@media (max-width: 768px) {
    .page {
        grid-template-columns: 1fr;
        grid-template-rows: 60px auto auto auto 50px;
        grid-template-areas:
            "header"
            "sidebar"
            "content"
            "aside"
            "footer";
    }
}
```

## 3. Flex vs Grid — що вибрати?

| Ситуація | Flexbox | Grid |
|----------|---------|------|
| Один рядок елементів | ✅ | ❌ |
| Центрування по горизонталі та вертикалі | ✅ | ✅ |
| Складний двовимірний макет | ❌ | ✅ |
| Перерозподіл простору між елементами | ✅ | ⚠️ |
| Адаптивна сітка без медіа-запитів | ⚠️ | ✅ (auto-fill/minmax) |
| Зміна порядку елементів | ✅ (order) | ✅ (grid-area) |

```css
/* Flexbox — для компонентів */
.card-row {
    display: flex;
    align-items: center;
    gap: 10px;
}

/* Grid — для макета сторінки */
.page-grid {
    display: grid;
    grid-template-columns: 1fr 3fr;
    gap: 20px;
}
```
