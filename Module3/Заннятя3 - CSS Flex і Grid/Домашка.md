## Домашнє завдання: CSS Flex і Grid

### Завдання 1. Flexbox навігація
Створіть навігацію з Flexbox:
1. Логотип зліва, посилання по центру, кнопка "Увійти" справа
2. При зменшенні екрану пункти меню ховаються в "бургер" (тільки CSS, без JS)
3. Використайте `gap` замість margin

### Завдання 2. Сітка карток
Створіть адаптивну сітку товарів:
1. Використайте Flexbox з `flex-wrap`
2. Кожна картка: зображення, назва, ціна, кнопка
3. При hover — картка піднімається
4. 4 колонки на десктопі, 2 на планшеті, 1 на телефоні

### Завдання 3. Grid макет сторінки
Створіть макет інтернет-магазину:
1. Grid з областями: header, nav, sidebar, main, footer
2. Бічна панель з фільтрами (категорії, ціна)
3. Основний контент з товарами (вкладений Grid)
4. Адаптивність через медіа-запити

### Завдання 4 (⭐ Зірочка). Grid галерея
Створіть галерею зображень:
1. Використайте `grid-auto-flow: dense` для заповнення порожнин
2. Деякі зображення займають 2 колонки (через клас .featured)
3. При hover — показувати підпис до зображення
4. Анімація появи при завантаженні

### Критерії прийому:
- Flexbox використано для одновимірних макетів
- Grid — для двовимірних
- Адаптивність без JS
- Валідний HTML та CSS
