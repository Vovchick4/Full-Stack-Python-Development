### Завдання 1
Використайте `https://jsonplaceholder.typicode.com/posts`:
- Напишіть async функцію `getPost(id)` — один пост
- `getAllPosts()` — всі пости
- `createPost(title, body)` — створити пост
- Виведіть заголовки всіх постів у консоль

### Завдання 2
Напишіть функцію, яка завантажує паралельно users та posts через Promise.all. Поверніть об'єкт { users, posts }.

### Завдання 3
Створіть функцію `getWithRetry(url, retries=3)`, яка при помилці повторює запит до retries разів. Використайте fetch + async/await.
