## 1. Асинхронність в JS

JavaScript — однопотоковий. Асинхронність дозволяє не блокувати виконання під час очікування (запити до API, таймери, читання файлів).

### Callback (старий спосіб)

```javascript
setTimeout(() => {
    console.log('Минуло 1 сек');
}, 1000);

// Callback hell — погано!
getUser(1, (user) => {
    getPosts(user.id, (posts) => {
        getComments(posts[0].id, (comments) => {
            console.log(comments);
        });
    });
});
```

## 2. Promise

```javascript
const fetchData = () => {
    return new Promise((resolve, reject) => {
        setTimeout(() => {
            const success = true;
            if (success) resolve({ id: 1, name: 'Дані' });
            else reject(new Error('Помилка'));
        }, 1000);
    });
};

fetchData()
    .then(data => console.log(data))
    .catch(error => console.error(error.message))
    .finally(() => console.log('Завершено'));

// Promise.all — паралельно
Promise.all([
    fetch('/api/users'),
    fetch('/api/posts'),
]).then(([users, posts]) => {
    console.log(users, posts);
});

// Promise.race — хто швидше
Promise.race([fetch('/api/fast'), fetch('/api/slow')]);
```

## 3. Async/Await (сучасний спосіб)

```javascript
const loadData = async () => {
    try {
        const data = await fetchData();
        console.log(data);
    } catch (error) {
        console.error('Помилка:', error);
    } finally {
        console.log('Готово');
    }
};

// Паралельні запити
const loadAll = async () => {
    const [users, posts] = await Promise.all([
        fetch('/api/users'),
        fetch('/api/posts'),
    ]);
    return { users, posts };
};
```

## 4. Fetch API — робота з HTTP

```javascript
// GET запит
const getUsers = async () => {
    const response = await fetch('https://jsonplaceholder.typicode.com/users');
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    const users = await response.json();
    return users;
};

// POST запит
const createUser = async (data) => {
    const response = await fetch('https://jsonplaceholder.typicode.com/users', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(data),
    });
    return response.json();
};

// PUT (оновлення)
const updateUser = async (id, data) => {
    const response = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`, {
        method: 'PUT',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(data),
    });
    return response.json();
};

// DELETE
const deleteUser = async (id) => {
    const response = await fetch(`https://jsonplaceholder.typicode.com/users/${id}`, {
        method: 'DELETE',
    });
    return response.ok;
};
```

## 5. REST API — основи

REST — архітектурний стиль для API.

| HTTP метод | CRUD | Опис |
|-----------|------|------|
| GET | Read | Отримати дані |
| POST | Create | Створити новий ресурс |
| PUT | Update | Оновити ресурс |
| PATCH | Update | Частково оновити |
| DELETE | Delete | Видалити |

### Статуси відповідей:
- 200 OK — успіх
- 201 Created — створено
- 400 Bad Request — невірний запит
- 401 Unauthorized — не авторизований
- 404 Not Found — не знайдено
- 500 Internal Server Error — помилка сервера

## 6. AJAX

AJAX (Asynchronous JavaScript and XML) — техніка для асинхронних запитів.

```javascript
// Старий спосіб (XMLHttpRequest)
const xhr = new XMLHttpRequest();
xhr.open('GET', 'https://api.example.com/users');
xhr.onload = () => console.log(JSON.parse(xhr.responseText));
xhr.send();

// Сучасний спосіб — fetch (вище)
```
