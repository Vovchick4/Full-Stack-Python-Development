## 1. Що таке HTML?

HTML (HyperText Markup Language) — це мова розмітки, яка використовується для створення структури веб-сторінок. HTML не є мовою програмування — це мова розмітки, яка за допомогою **тегів** описує, де знаходиться заголовок, де абзац, де зображення, а де посилання.

Браузер отримує HTML-код, аналізує його і відображає сторінку у зрозумілому для користувача вигляді.

## 2. Анатомія HTML-елемента

```html
<!-- Повний елемент -->
<тег атрибут="значення">Вміст</тег>
```

Елемент складається з:
- **Відкриваючий тег** — `<p>`
- **Вміст** — текст або інші елементи всередині
- **Закриваючий тег** — `</p>` (з косою рискою)
- **Атрибут** — додаткова інформація про елемент

```html
<p>Це простий абзац</p>

<a href="https://example.com" target="_blank" title="Підказка">
    Текст посилання
</a>
```

### Атрибути

| Атрибут | Опис | Приклад |
|---------|------|---------|
| `id` | Унікальний ідентифікатор | `id="header"` |
| `class` | Клас для CSS | `class="card active"` |
| `style` | Інлайн CSS | `style="color: red"` |
| `title` | Підказка при наведенні | `title="Детальніше"` |
| `lang` | Мова вмісту | `lang="uk"` |
| `data-*` | Власні дані | `data-id="123"` |

### Вкладені елементи

Елементи можуть бути вкладеними один в одного:

```html
<p>Це <strong>дуже <em>важливий</em></strong> текст.</p>
```

### Пусті (void) елементи

Деякі елементи не мають вмісту і закриваючого тега:

```html
<br>   <!-- перенос рядка -->
<hr>   <!-- горизонтальна лінія -->
<img>  <!-- зображення -->
<input> <!-- поле вводу -->
<meta> <!-- мета-дані -->
<link> <!-- підключення ресурсів -->
```

### HTML-коментарі

```html
<!-- Це коментар — браузер його не показує -->
<!--
    Багаторядковий
    коментар
-->
```

## 3. Базова структура HTML-документа

```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Опис сторінки">
    <meta name="keywords" content="html, навчання, програмування">
    <meta name="author" content="Ім'я автора">
    <title>Назва сторінки</title>
    <link rel="stylesheet" href="style.css">
    <link rel="icon" href="favicon.ico" type="image/x-icon">
</head>
<body>
    <!-- Весь видимий контент тут -->
</body>
</html>
```

### Елементи `<head>`:

| Елемент | Призначення |
|---------|-------------|
| `<title>` | Заголовок вкладки браузера |
| `<meta charset="UTF-8">` | Кодування символів (обов'язково) |
| `<meta name="viewport">` | Адаптація під мобільні |
| `<meta name="description">` | Опис для пошукових систем |
| `<link rel="stylesheet">` | Підключення CSS |
| `<link rel="icon">` | Іконка сайту (favicon) |

## 4. Текст та заголовки

### Заголовки (h1-h6)

```html
<h1>Головний заголовок сторінки (один на сторінку)</h1>
<h2>Заголовок розділу</h2>
<h3>Підзаголовок</h3>
<h4>Заголовок 4-го рівня</h4>
<h5>Заголовок 5-го рівня</h5>
<h6>Заголовок 6-го рівня</h6>
```

**Правила:**
- `<h1>` — один на сторінку, містить головну тему
- Заголовки будують ієрархію: h1 → h2 → h3 (не пропускайте рівні)
- Не використовуйте заголовки для зміни розміру тексту (для цього є CSS)

### Абзаци та форматування

```html
<p>Звичайний абзац тексту.</p>

<p>
    Абзац може містити 
    <strong>жирний текст</strong>,
    <em>курсив (виділення)</em>,
    <u>підкреслений</u>,
    <s>закреслений</s>.
</p>

<p>
    <small>Дрібний текст</small><br>
    H<sub>2</sub>O (нижній індекс)<br>
    м<sup>2</sup> (верхній індекс)<br>
    <mark>Виділений текст</mark><br>
    <del>Видалений</del> <ins>Вставлений</ins><br>
    <code>код</code> <kbd>клавіша</kbd> <samp>вивід</samp><br>
    <abbr title="HyperText Markup Language">HTML</abbr>
</p>

<blockquote>
    Довга цитата (з відступом)
    <cite>— Джерело</cite>
</blockquote>

<p>Коротка цитата: <q>Бути чи не бути</q></p>

<pre>
    Текст     зі    збереженням
    пробілів
    та переносів рядків
</pre>
```

## 5. Списки

### Невпорядкований список (ul)

```html

    <li>Хліб</li>
    <li>Молоко</li>
    <li>Яйця</li>

```

### Впорядкований список (ol)

```html

    <li>Відкрити кришку</li>
    <li>Вилити воду</li>
    <li>Закрити кришку</li>
</ol>

<ol type="A">   <!-- A, B, C... -->

<ol type="I">   <!-- I, II, III... -->
<ol start="5">  <!-- почати з 5 -->
```

```html

    <dt>HTML</dt>
    <dd>Мова розмітки гіпертексту</dd>
```


## 6. Посилання

```html
<!-- Зовнішнє посилання -->
<a href="https://example.com">Перейти на сайт</a>

<!-- Відносне (внутрішнє) -->

<!-- Якір на елемент -->
<a href="#section2">Перейти до розділу 2</a>
...
<h2 id="section2">Розділ 2</h2>

<!-- Email та телефон -->
<a href="mailto:info@example.com">Написати листа</a>
<a href="tel:+380501234567">Зателефонувати</a>

<!-- Відкриття в новій вкладці -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
    Зовнішній ресурс
</a>

<!-- Атрибути посилань -->
<a href="file.pdf" download>Завантажити файл</a>
<a href="#top" title="Нагору сторінки">↑</a>
<a href="https://example.com" hreflang="en">English version</a>
```

## 7. Зображення

```html
<!-- Просте зображення -->

     width="200" 
     height="100"
     title="Наш логотип"
     loading="lazy">

    <img src="diagram.png" alt="Схема архітектури">
    <figcaption>Рис. 1. Архітектура веб-додатку</figcaption>

<!-- JPEG/JPG — фото, градієнти (стискає, втрати якості) -->

<!-- GIF — анімація (обмежена палітра кольорів) -->
<!-- SVG — векторна графіка (масштабується, код) -->
<!-- WebP — сучасний формат (краще стиснення) -->
<!-- AVIF — найновіший формат (найкраще стиснення) -->
```

## 8. Семантичні теги HTML5

Семантичні теги описують **призначення** контенту, а не тільки його вигляд. Це важливо для SEO, доступності (screen readers) і читабельності коду.

```html
<body>
    <header>
        <h1>Назва сайту</h1>
        <nav>
            <ul>
                <li><a href="/">Головна</a></li>
                <li><a href="/blog">Блог</a></li>
                <li><a href="/contact">Контакти</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <article>
            <header>
                <h2>Заголовок статті</h2>
                <time datetime="2025-01-15">15 січня 2025</time>
            </header>
            
            <section>
                <h3>Вступ</h3>
                <p>Текст вступу...</p>
            </section>
            
            <section>
                <h3>Основна частина</h3>
                <p>Детальний опис...</p>
            </section>
            
            <footer>
                <p>Автор: Ім'я Прізвище</p>
            </footer>
        </article>

        <aside>
            <h3>Бокова панель</h3>
            <ul>
                <li><a href="#">Пов'язана стаття 1</a></li>
                <li><a href="#">Пов'язана стаття 2</a></li>
            </ul>
        </aside>
    </main>

    <footer>
        <p>&copy; 2025 Всі права захищено</p>
    </footer>
</body>
```

### Призначення семантичних тегів

| Тег | Призначення |
|-----|-------------|
| `<header>` | Шапка сайту або розділу |
| `<nav>` | Навігація (меню) |
| `<main>` | Головний контент (один на сторінку) |
| `<section>` | Логічна секція |
| `<article>` | Незалежна стаття/запис |
| `<aside>` | Бічна панель, додатковий контент |
| `<footer>` | Підвал сайту або розділу |
| `<figure>` | Ілюстрація/діаграма |
| `<figcaption>` | Підпис до figure |
| `<time>` | Дата/час |
| `<mark>` | Виділений текст |
| `<details>` | Розгортаємий блок |
| `<summary>` | Заголовок для details |

```html
<details>
    <summary>Натисніть, щоб розгорнути</summary>
    <p>Прихований текст, який з'являється при кліку.</p>
</details>
```


## 12. div та span

```html
    <div class="card">
        <p>Текст у картці</p>
    </div>
```
