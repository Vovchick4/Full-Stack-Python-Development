## 1. Одиниці вимірювання

```css
/* Абсолютні */
.px { font-size: 16px; }
.pt { font-size: 12pt; }

/* Відносні */
.em { font-size: 1.5em; }     /* відносно батька */
.rem { font-size: 1.5rem; }   /* відносно html (16px) */
.vw { width: 50vw; }          /* % від ширини вікна */
.vh { height: 100vh; }        /* % від висоти вікна */
.pcnt { width: 50%; }         /* відносно батька */
```

## 2. Позиціювання (position)

```css
.static { position: static; }     /* за замовчуванням */

.relative {
    position: relative;
    top: 20px;
    left: 30px;
}

.absolute {
    position: absolute;
    top: 0;
    right: 0;
    /* відносно найближчого relative-батька */
}

.fixed {
    position: fixed;
    bottom: 20px;
    right: 20px;
    /* прикріплено до вікна, не рухається при скролі */
}

.sticky {
    position: sticky;
    top: 0;
    /* relative → fixed при скролі */
}
```

## 3. Поліоформлення та відступи

```css
/* margin — зовнішні відступи */
margin: 10px;                   /* з усіх боків */
margin: 10px 20px;              /* верх/низ, ліво/право */
margin: 10px 20px 30px 40px;    /* верх, право, низ, ліво */
margin-top: 10px;
margin: 0 auto;                 /* центрування блоку */

/* padding — внутрішні відступи */
padding: 20px;
padding: 10px 20px;

/* Схлопування margin */
/* Відступи сусідніх блоків не сумуються, а беруться по максимуму */
```

## 4. overflow

```css
.visible { overflow: visible; }  /* видимий за межами */
.hidden { overflow: hidden; }    /* обрізає */
.scroll { overflow: scroll; }    /* завжди скрол */
.auto { overflow: auto; }        /* скрол при потребі */
.xy { overflow-x: hidden; overflow-y: auto; }
```

## 5. Порядок верстки блоку (нормальний потік)

1. Блокові елементи (div, p, h1) — кожен з нового рядка
2. Інлайнові (span, a, strong) — в одному рядку
3. Зміна через display (flex, grid, inline-block)
4. Відступи margin/padding, рамки
5. Позиціювання (relative, absolute, fixed) змінює потік

## 6. z-index (накладання)

```css
.overlay { z-index: 100; }
/* Працює тільки з position != static */
/* Чим більше — тим вище шар */
```
