## Домашнє завдання: Основи React

### Завдання 1. Компоненти та Props
Створіть компонент `ProductCard`:
- Приймає: title, price, image, isNew (bool)
- Показує картку товару зі стилями
- Якщо isNew — показує бейдж "Новинка"
- Використайте Card в App з масивом товарів

### Завдання 2. State та події
Створіть компонент `ShopCart`:
- Список товарів з кнопками +/-
- Загальна вартість (розраховується автоматично)
- Кнопка "Очистити кошик"
- Кнопка "Видалити" для кожного товару

### Завдання 3. useEffect та API
Створіть компонент `Posts`:
- Завантажує пости з `https://jsonplaceholder.typicode.com/posts`
- Показує loader під час завантаження
- Обробляє помилки
- Пошук/фільтрація за title (input)
- Пагінація (10 постів на сторінку)

### Завдання 4. Композиція компонентів
Створіть Todo App з компонентів:
- `App` — кореневий (керує станом)
- `TodoForm` — форма додавання
- `TodoList` — список справ
- `TodoItem` — одна справа (текст, чекбокс, видалення)
- `TodoFilter` — кнопки "Всі", "Активні", "Виконані"

### Критерії прийому:
- Компоненти мають чіткі назви та відповідальність
- State піднято на правильний рівень
- Використано map, filter, conditional rendering
- Код без помилок у консолі
