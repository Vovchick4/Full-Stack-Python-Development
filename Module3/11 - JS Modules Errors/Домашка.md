### Завдання 1
Розбийте попередній код (класи) на модулі:
- `models/Product.js` — класи
- `utils/validators.js` — функції валідації
- `app.js` — імпорт і використання

### Завдання 2
Напишіть функцію parseJSON(str), яка приймає рядок JSON і повертає об'єкт. Якщо рядок невалідний — повертає { error: 'Помилка парсингу' } (використайте try/catch).

### Завдання 3
Створіть функції для роботи з cookies: setCookie(name, value, days), getCookie(name), deleteCookie(name). Протестуйте в браузері.
