## 1. DOM (Document Object Model)

DOM — це програмний інтерфейс до HTML. JS може змінювати структуру, стилі та вміст сторінки через DOM.

### Пошук елементів

```javascript
// Один елемент
const app = document.getElementById('app');
const btn = document.querySelector('#btn');
const firstItem = document.querySelector('.item');

// Колекції
const items = document.querySelectorAll('.item');   // NodeList (forEach!)
const btns = document.getElementsByTagName('button');
```

### Зміна елементів

```javascript
const item = document.querySelector('.item');

// Текст
item.textContent = 'Новий текст';
item.innerText = 'Текст';       // враховує CSS

// HTML
item.innerHTML = '<strong>Текст</strong>';

// Атрибути
item.getAttribute('data-id');    // '1'
item.setAttribute('data-id', '10');
item.hasAttribute('data-id');
item.removeAttribute('data-id');

// Data-атрибути
item.dataset.id;            // data-id
item.dataset.userRole;      // data-user-role

// Класи
item.classList.add('active');
item.classList.remove('active');
item.classList.toggle('active');
item.classList.contains('active');

// Стилі
item.style.color = 'red';
item.style.backgroundColor = '#f0f0f0';
```

### Створення та видалення

```javascript
const div = document.createElement('div');
div.textContent = 'Новий блок';
div.classList.add('card');

const parent = document.querySelector('.container');
parent.appendChild(div);     // в кінець
parent.prepend(div);         // на початок
parent.insertBefore(div, parent.children[0]);

parent.insertAdjacentHTML('beforeend', '<div>Ще</div>');
div.remove();
```

## 2. Події (Events)

```javascript
// Додавання події
const btn = document.querySelector('#btn');
btn.addEventListener('click', () => {
    console.log('Клік!');
});

btn.addEventListener('click', function(event) {
    console.log(event.target);        // на що клікнули
    console.log(event.currentTarget); // на чому обробник
    event.preventDefault();           // скасувати стандартну дію
    event.stopPropagation();          // зупинити спливання
});

// Видалення події
const handler = () => console.log('Клік');
btn.addEventListener('click', handler);
btn.removeEventListener('click', handler);
```

## 3. Делегування подій

```javascript
// Замість обробника на кожен li — один на батька
const list = document.querySelector('.list');
list.addEventListener('click', (event) => {
    const li = event.target.closest('li');
    if (!li) return;  // клікнули не на li
    console.log(li.textContent);
});
```

## 4. LocalStorage та SessionStorage

```javascript
// LocalStorage — дані назавжди (доки не видалити вручну)
localStorage.setItem('theme', 'dark');
localStorage.getItem('theme');     // 'dark'
localStorage.removeItem('theme');
localStorage.clear();              // все!

// SessionStorage — дані до закриття вкладки
sessionStorage.setItem('key', 'value');
sessionStorage.getItem('key');

// Для об'єктів:
const user = { name: 'Олена', age: 25 };
localStorage.setItem('user', JSON.stringify(user));
const saved = JSON.parse(localStorage.getItem('user'));
```
