### Завдання 1
Створіть Todo List: input + кнопка "Додати". При кліку — додається li з текстом. При кліку на li — перекреслюється (toggle class 'done'). Кнопка "×" видаляє. Лічильник активних завдань оновлюється. Збереження в localStorage.

### Завдання 2
Створіть таблицю користувачів: форма (ім'я, email, вік) + таблиця. Додавання рядка при сабміті. Видалення рядка. Сортування за ім'ям. Дані зберігаються в localStorage.

### Завдання 3
Створіть акордеон (FAQ): при кліку на питання — відкривається відповідь. При відкритті одного — інші закриваються. Анімація через CSS transition (max-height).
