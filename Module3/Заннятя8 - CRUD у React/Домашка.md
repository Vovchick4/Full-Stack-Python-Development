## Домашнє завдання: CRUD у React

### Завдання 1. CRUD без API (локальний state)
Створіть додаток "Список нотаток":
1. CREATE — форма з полями: title, content, priority (low/medium/high)
2. READ — список нотаток з фільтром за priority
3. UPDATE — редагування нотатки (inline або модалка)
4. DELETE — з підтвердженням
5. Лічильник "Всього: X" нагорі

### Завдання 2. CRUD з API
Використайте `json-server` (або `https://jsonplaceholder.typicode.com/posts`):
1. GET /posts — завантажити всі пости
2. POST /posts — створити новий (відправте { title, body, userId: 1 })
3. PUT /posts/:id — оновити
4. DELETE /posts/:id — видалити
5. Обробка помилок та loader

### Завдання 3. Пошук та фільтрація
Додайте до списку товарів:
1. Пошук за назвою (input, фільтрує в реальному часі)
2. Сортування за ціною (за зростанням/спаданням)
3. Фільтр за категорією (кнопки "Всі", "Електроніка", "Одяг")
4. Пагінація (4 товари на сторінку)

### Завдання 4 (⭐ Зірочка). LocalStorage + Undo
1. Зберігайте всі дані в localStorage
2. При завантаженні сторінки — відновлюйте з localStorage
3. Додайте "Кошик" — товари, які можна додавати/видаляти з кошика
4. Додайте кнопку "Undo" для останнього видалення

### Критерії прийому:
- Всі CRUD операції працюють
- State керується через відповідні хуки (useState, useEffect)
- API запити з async/await та try/catch
- Компоненти розділені за відповідальністю
- UI оновлюється після кожної операції
