## 1. BEM (Block Element Modifier)

Методологія іменування класів для масштабованих проектів.

```css
/* Block — компонент */
.card {}

/* Element — частина блоку */
.card__title {}
.card__image {}
.card__button {}

/* Modifier — стан/варіація */
.card--featured {}
.card__button--primary {}
.card__button--disabled {}

/* HTML */
<div class="card card--featured">
    <h2 class="card__title">Назва</h2>
    <button class="card__button card__button--primary">Купити</button>
</div>
```

### Правила BEM
- Тільки класи (без ID, без вкладених селекторів)
- Блок — незалежний компонент
- Елемент завжди всередині блоку
- Модифікатор змінює вигляд блоку або елемента

## 2. Трансформації та переходи

```css
/* Переходи (плавна зміна) */
.card {
    transition: all 0.3s ease;
    transition: transform 0.3s, background 0.2s;
}
.card:hover { transform: translateY(-5px); }

/* Трансформації */
.rotate { transform: rotate(45deg); }
.scale  { transform: scale(1.5); }
.translate { transform: translate(50px, 100px); }
.skew   { transform: skew(10deg); }
.multi  { transform: rotate(45deg) scale(1.2); }
```

## 3. CSS анімації (Keyframes)

```css
@keyframes fadeIn {
    from { opacity: 0; transform: translateY(20px); }
    to   { opacity: 1; transform: translateY(0); }
}

@keyframes spin {
    0%   { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
}

.animated {
    animation: fadeIn 0.5s ease-out;
    animation: spin 1s linear infinite;
}

.loader {
    width: 40px; height: 40px;
    border: 4px solid #f3f3f3;
    border-top: 4px solid #3498db;
    border-radius: 50%;
    animation: spin 1s linear infinite;
}
```

## 4. Retina підтримка

```css
/* Retina (2x, 3x екрани) */
.image {
    background-image: url('image.jpg');
}
@media (-webkit-min-device-pixel-ratio: 2) {
    .image { background-image: url('image@2x.jpg'); }
}

/* Або через srcset в HTML */
<img src="image.jpg" srcset="image@2x.jpg 2x, image@3x.jpg 3x" alt="img">
```

## 5. Web Accessibility (A11y)

```html
<!-- Семантичні теги для скрінрідерів -->
<nav aria-label="Головна навігація">
<button aria-label="Закрити">×</button>
<img alt="Опис зображення">

<!-- ARIA атрибути -->
<div role="alert">Помилка!</div>
<div aria-hidden="true">декоративний елемент</div>
<button aria-expanded="false">Меню</button>

<!-- Фокус та клавіатура -->
<a href="#" tabindex="0">Фокусоване посилання</a>
```

## 6. Mobile First

```css
/* Спочатку базові стилі для телефону */
.container { display: block; }

/* Потім додаємо для більших екранів */
@media (min-width: 768px) {
    .container { display: flex; }
}
@media (min-width: 1200px) {
    .container { max-width: 1200px; margin: 0 auto; }
}
```

### Кросбраузерність — часті проблеми
```css
/* Вендорні префікси */

    -ms-transform: rotate(45deg);      /* IE */
    -o-transform: rotate(45deg);       /* Opera */
```
