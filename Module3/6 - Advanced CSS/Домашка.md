### Завдання 1
Перепишіть CSS ваших попередніх проектів у методології BEM (назви класів: блок__елемент--модифікатор).

### Завдання 2
Створіть анімований loader (спінер), додайте анімацію появи для карток (fadeIn з translateY). Кожна картка з'являється з затримкою (animation-delay).

### Завдання 3
Створіть сторінку з Mobile First підходом. Базові стилі для телефону (max-width: 480px), додайте для планшета (768px) і десктопа (1200px). Додайте aria-атрибути.
