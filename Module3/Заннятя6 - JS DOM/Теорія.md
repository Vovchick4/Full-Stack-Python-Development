## 1. Що таке DOM?

DOM (Document Object Model) — це програмний інтерфейс до HTML-документа. JS може змінювати структуру, стилі та вміст сторінки через DOM.

```
window
└── document
    └── html
        ├── head
        │   ├── title
        │   └── meta
        └── body
            ├── header
            ├── main
            │   ├── section
            │   └── article
            └── footer
```

## 2. Пошук елементів

```html
<div id="app">
    <ul class="list">
        <li class="item" data-id="1">Перший</li>
        <li class="item active" data-id="2">Другий</li>
        <li class="item" data-id="3">Третій</li>
    </ul>
    <button id="btn">Натисни</button>
</div>
```

```javascript
// Один елемент
const app = document.getElementById('app');
const btn = document.querySelector('#btn');
const firstItem = document.querySelector('.item');  // перший li
const activeItem = document.querySelector('.item.active');

// Колекції
const items = document.querySelectorAll('.item');     // NodeList (forEach!)
const itemsByClass = document.getElementsByClassName('item');  // HTMLCollection
const itemsByTag = document.getElementsByTagName('li');
const itemsByName = document.getElementsByName('username');

// Перевірка
if (btn) { console.log('Знайдено!'); }

// Обхід DOM
const parent = firstItem.parentElement;           // ul
const children = parent.children;                 // всі li
const next = firstItem.nextElementSibling;        // наступний li
const prev = firstItem.previousElementSibling;    // null
const first = parent.firstElementChild;
const last = parent.lastElementChild;
```

## 3. Зміна вмісту та атрибутів

```javascript
const item = document.querySelector('.item');

// Текст
item.textContent = 'Новий текст';           // без HTML
item.innerText = 'Текст';                   // враховує CSS (повільніше)

// HTML
item.innerHTML = '<strong>Жирний</strong>';  // HTML всередині
// item.outerHTML = '<div>Заміна</div>';     // заміна всього елемента

// Атрибути
item.getAttribute('data-id');           // '1'
item.setAttribute('data-id', '10');
item.hasAttribute('data-id');           // true
item.removeAttribute('data-id');

// Data-атрибути
item.dataset.id;         // '1'
item.dataset.userRole;   // якщо data-user-role
item.dataset.id = '5';

// Класи
item.classList.add('highlight');
item.classList.remove('active');
item.classList.toggle('active');      // додати/прибрати
item.classList.contains('active');    // true/false
item.classList.replace('old', 'new');

// Стилі
item.style.color = 'red';
item.style.backgroundColor = '#f0f0f0';
item.style.fontSize = '18px';
item.style.cssText = 'color: red; background: blue;';
```

## 4. Створення та видалення елементів

```javascript
// Створення
const newItem = document.createElement('li');
newItem.textContent = 'Новий елемент';
newItem.classList.add('item');

// Додавання
const list = document.querySelector('.list');
list.appendChild(newItem);                // в кінець
list.prepend(newItem);                    // на початок
list.insertBefore(newItem, list.children[1]);  // перед другим
list.insertAdjacentElement('beforeend', newItem);

// Текст або HTML поруч
list.insertAdjacentHTML('beforeend', '<li>Ще один</li>');
list.insertAdjacentText('afterbegin', 'Перед списком');

// Видалення
newItem.remove();                         // сучасно
list.removeChild(newItem);                // через батька

// Клонування
const clone = newItem.cloneNode(true);    // true = з дітьми
```

## 5. Події (Events)

```javascript
const btn = document.querySelector('#btn');
const list = document.querySelector('.list');

// Базове додавання події
btn.addEventListener('click', () => {
    console.log('Кнопку натиснуто!');
});

// Видалення події
const handler = () => console.log('Клік');
btn.addEventListener('click', handler);
btn.removeEventListener('click', handler);

// Об'єкт події
btn.addEventListener('click', (event) => {
    console.log(event.target);      // на що клікнули
    console.log(event.currentTarget); // на чому обробник
    event.preventDefault();         // скасувати стандартну дію
    event.stopPropagation();        // зупинити спливання
});

// Основні події
// Миша: click, dblclick, mouseover, mouseout, mousedown, mouseup
// Клавіатура: keydown, keyup, keypress
// Форма: submit, change, input, focus, blur
// Документ: DOMContentLoaded, load, scroll, resize
// Інші: dragstart, drop, transitionend, animationend
```

### Делегування подій

```javascript
// Замість додавання обробника на кожен li — один на батька
list.addEventListener('click', (event) => {
    const item = event.target.closest('.item');
    if (!item) return;  // клікнули не на item

    console.log('Клікнуто на:', item.textContent);
    console.log('ID:', item.dataset.id);
});
```

## 6. Форми

```javascript
const form = document.querySelector('#myForm');

form.addEventListener('submit', (event) => {
    event.preventDefault();  // не перезавантажувати сторінку

    const formData = new FormData(form);
    const data = Object.fromEntries(formData);

    console.log(data);  // { name: '...', email: '...' }

    // Або вручну:
    const name = form.querySelector('#name').value;
    const email = form.querySelector('#email').value;
});

// Валідація на льоту
const emailInput = document.querySelector('#email');
emailInput.addEventListener('input', () => {
    if (emailInput.validity.valid) {
        emailInput.classList.remove('invalid');
        emailInput.classList.add('valid');
    } else {
        emailInput.classList.remove('valid');
        emailInput.classList.add('invalid');
    }
});
```

## 7. Практичний приклад: Todo List

```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Todo List</title>
    <style>
        body { font-family: Arial; max-width: 500px; margin: 50px auto; }
        .todo-input { display: flex; gap: 10px; margin-bottom: 20px; }
        .todo-input input { flex: 1; padding: 10px; font-size: 16px; }
        .todo-input button { padding: 10px 20px; background: #007bff; color: white; border: none; cursor: pointer; }
        .todo-item { display: flex; justify-content: space-between; padding: 10px; border-bottom: 1px solid #ddd; }
        .todo-item.done { text-decoration: line-through; color: #999; }
        .delete { background: #dc3545; color: white; border: none; padding: 5px 10px; cursor: pointer; }
    </style>
</head>
<body>
    <h1>Мої справи</h1>
    <div class="todo-input">
        <input type="text" id="todoInput" placeholder="Додати справу...">
        <button id="addBtn">Додати</button>
    </div>
    <div id="todoList"></div>

    <script>
        const input = document.getElementById('todoInput');
        const addBtn = document.getElementById('addBtn');
        const todoList = document.getElementById('todoList');

        // Додавання
        addBtn.addEventListener('click', () => {
            const text = input.value.trim();
            if (!text) return;

            const item = document.createElement('div');
            item.className = 'todo-item';
            item.innerHTML = `
                <span>${text}</span>
                <button class="delete">×</button>
            `;

            // Відмітка виконано
            item.addEventListener('click', (e) => {
                if (e.target.tagName !== 'BUTTON') {
                    item.classList.toggle('done');
                }
            });

            // Видалення
            item.querySelector('.delete').addEventListener('click', () => {
                item.remove();
            });

            todoList.appendChild(item);
            input.value = '';
        });

        // Enter = додати
        input.addEventListener('keypress', (e) => {
            if (e.key === 'Enter') addBtn.click();
        });
    </script>
</body>
</html>
```
