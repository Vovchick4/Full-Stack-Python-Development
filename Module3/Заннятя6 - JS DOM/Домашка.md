## Домашнє завдання: JS DOM

### Завдання 1. Динамічний список
Створіть HTML сторінку з:
1. Input та кнопкою "Додати"
2. Списком (ul), куди додаються елементи
3. Кожен елемент має кнопку "Видалити"
4. При кліку на елемент — він перекреслюється (toggle class)
5. Лічильник активних елементів оновлюється автоматично

### Завдання 2. Таблиця з даними
Створіть сторінку "Користувачі":
1. Форма з полями: ім'я, email, вік
2. Таблиця, де відображаються додані користувачі
3. Кнопка "Видалити" в кожному рядку
4. Кнопка "Сортувати за ім'ям"
5. Збереження в localStorage (щоб дані не зникали при перезавантаженні)

### Завдання 3. Слайдер зображень
Створіть простий слайдер:
1. Масив з 5 зображень (можна використати picsum.photos)
2. Кнопки "Назад" та "Вперед"
3. Індикатор поточного зображення (крапки)
4. Автоматична зміна кожні 3 секунди
5. Пауза при наведенні миші

### Завдання 4 (⭐ Зірочка). Акордеон
Створіть акордеон (FAQ):
1. Список питань; при кліку — відкривається відповідь
2. При відкритті одного — інші закриваються
3. Анімація відкриття/закриття (max-height + transition)
4. Іконка +/− змінюється при відкритті

### Критерії прийому:
- Жодного HTML у JS (тільки createElement та шаблонні рядки)
- Використано делегування подій
- Код організовано в функції
- Сторінка працює без помилок у консолі
