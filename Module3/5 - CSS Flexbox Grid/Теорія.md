## 1. Flexbox (одновимірний макет)

### Flex Container

```css
.container {
    display: flex;
    flex-direction: row;           /* column, row-reverse, column-reverse */
    flex-wrap: wrap;               /* перенос на новий рядок */
    flex-flow: row wrap;           /* скорочення direction + wrap */

    justify-content: center;       /* flex-start, flex-end, space-between, space-around, space-evenly */
    align-items: center;           /* flex-start, flex-end, stretch, baseline */
    align-content: center;         /* для багаторядкових flex контейнерів */
    gap: 20px;                     /* відступи між елементами */
}
```

### Flex Items

```css
.item {
    flex: 1;                  /* flex-grow: 1; flex-shrink: 1; flex-basis: 0 */
    flex: 0 0 200px;          /* не росте, не стискається, ширина 200px */
    order: -1;                /* порядок (за замовч. 0) */
    align-self: center;       /* індивідуальне вирівнювання */
}
```

### Приклад: навігація

```css
.nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 0 20px;
}
.nav-links { display: flex; gap: 15px; list-style: none; }
```

### Приклад: картки

```css
.grid {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}
.card { flex: 1 1 300px; }
```

## 2. CSS Grid (двовимірний макет)

### Grid Container

```css
.grid {
    display: grid;
    grid-template-columns: 200px 1fr 1fr;            /* 3 колонки */
    grid-template-columns: repeat(3, 1fr);            /* 3 рівні */
    grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));  /* адаптивно */
    gap: 20px;
}
```

### Grid Items

```css
.item { grid-column: span 2; grid-row: span 2; }
.header { grid-column: 1 / -1; }
```

### Приклад: макет сторінки

```css
.page {
    display: grid;
    grid-template-columns: 250px 1fr;
    grid-template-rows: 80px 1fr 60px;
    grid-template-areas:
        "header header"
        "sidebar content"
        "footer footer";
    min-height: 100vh;
}
header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
footer  { grid-area: footer; }
```

## 3. Адаптивність (Media Queries)

```css
/* Телефони */
@media (max-width: 480px) {
    .page { grid-template-columns: 1fr; }
    .grid { flex-direction: column; }
}

/* Планшети */
@media (max-width: 768px) {
    .nav { flex-direction: column; }
}

/* Mobile First — спочатку мобілка */
.container { display: flex; flex-direction: column; }
@media (min-width: 768px) {
    .container { flex-direction: row; }
}
```
