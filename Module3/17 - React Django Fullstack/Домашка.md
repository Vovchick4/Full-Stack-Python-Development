### Завдання 1
Створіть Django проект "blog" з моделлю Post (title, content, author). Додайте DRF ModelViewSet. Налаштуйте CORS.

### Завдання 2
Створіть React додаток, який: завантажує пости з Django API, відображає список, дозволяє створювати нові через форму. Повний CRUD цикл.

### Завдання 3 (⭐ Зірочка)
Додайте JWT аутентифікацію: сторінка логіну, збереження токена, захищені маршрути (тільки авторизовані можуть створювати пости). Налаштуйте Docker + docker-compose.
