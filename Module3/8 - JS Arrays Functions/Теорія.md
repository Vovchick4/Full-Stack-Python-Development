## 1. Масиви

```javascript
const fruits = ['яблуко', 'банан', 'апельсин'];
const mixed = [1, 'text', true, { key: 'value' }];
const empty = [];

// Доступ
fruits[0];         // 'яблуко'
fruits.length;     // 3
fruits[fruits.length - 1]; // останній

// Методи
fruits.push('груша');       // додати в кінець
fruits.pop();                // видалити з кінця
fruits.unshift('груша');    // додати на початок
fruits.shift();              // видалити з початку
fruits.indexOf('банан');    // 1
fruits.includes('груша');   // true/false
fruits.slice(1, 3);          // зріз (копія частини)
fruits.splice(1, 1);         // видалити 1 елемент з позиції 1

// forEach — просто перебрати
fruits.forEach(f => console.log(f));

// map — перетворити
[1, 2, 3].map(n => n * 2);   // [2, 4, 6]

// filter — відфільтрувати
[1, 2, 3, 4].filter(n => n > 2); // [3, 4]

// reduce — згорнути в одне значення
[1, 2, 3].reduce((sum, n) => sum + n, 0); // 6

// find — знайти перший
[1, 2, 3].find(n => n > 1);  // 2

// sort — сортувати
[3, 1, 2].sort((a, b) => a - b); // [1, 2, 3]
```

## 2. Цикли

```javascript
// for (класичний)
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// for...of (для масивів)
for (const fruit of fruits) {
    console.log(fruit);
}

// for...in (для об'єктів)
for (const key in obj) { }

// while
let i = 0;
while (i < 5) { i++; }

// do...while
do { i++; } while (i < 5);
```

## 3. Функції

```javascript
// Function declaration (можна викликати до оголошення)
function add(a, b) { return a + b; }

// Function expression
const multiply = function(a, b) { return a * b; };

// Arrow function (сучасна)
const subtract = (a, b) => a - b;
const double = x => x * 2;
const greet = () => 'Hello!';

// Параметри за замовчуванням
const greetUser = (name = 'Гість') => `Привіт, ${name}!`;

// Rest параметри (будь-яка кількість)
const sum = (...nums) => nums.reduce((a, b) => a + b, 0);
sum(1, 2, 3, 4); // 10
```

## 4. Область видимості (Scope)

```javascript
// Глобальна область
const globalVar = 'доступно всюди';

function example() {
    // Локальна область функції
    const localVar = 'тільки в функції';

    if (true) {
        // Блочна область (для let/const)
        const blockVar = 'тільки в блоці';
        var oldVar = 'доступно в функції'; // var ігнорує блоки!
    }
    // console.log(blockVar); // Error!
    console.log(oldVar);     // OK
}
```

### Лексичне оточення
Кожна функція "запам'ятовує" область, де була створена (scope chain).
