## Домашнє завдання: Повна зв'язка React + Django

### Завдання 1. Django Backend
Створіть Django проект "blog" з:
1. Моделлю Post (title, content, author, created_at, is_published)
2. DRF серіалізатором та ModelViewSet
3. Фільтрацією за is_published та author
4. Пошуком за title
5. CORS налаштований для React

### Завдання 2. React Frontend
Створіть React додаток "blog-frontend":
1. BlogList — список постів з API
2. BlogForm — створення нового поста
3. BlogDetail — сторінка одного поста
4. Поля: title (input), content (textarea), author (input)
5. Обробка помилок та loader

### Завдання 3. Аутентифікація
Додайте JWT аутентифікацію:
1. Сторінка логіну (username + password)
2. Збереження токена в localStorage
3. Автоматичне додавання Authorization: Bearer header
4. Захищені маршрути (тільки авторизовані можуть створювати пости)
5. Logout

### Завдання 4 (⭐ Зірочка). Full-Stack Deploy
1. Налаштуйте Docker для Django + PostgreSQL
2. Зберіть React (npm run build)
3. Налаштуйте Django роздавати статику React
4. Створіть docker-compose.yml з усіма сервісами
5. Переконайтеся, що все працює на одному порту

### Критерії прийому:
- Django API працює (перевірте через Postman або browser)
- React отримує дані з Django
- CORS не блокує запити
- CRUD операції проходять повний цикл (React -> Django -> DB -> назад)
- Аутентифікація захищає відповідні маршрути
