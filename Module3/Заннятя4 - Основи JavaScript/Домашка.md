## Домашнє завдання: Основи JavaScript

### Завдання 1. Змінні та типи
1. Створіть змінні для: назви товару, ціни, кількості, чи є знижка
2. Виведіть в консоль рядок: "Товар X коштує Y грн. Кількість: Z"
3. Порахуйте загальну вартість (ціна * кількість) з урахуванням знижки 10%

### Завдання 2. Робота з масивами
Створіть масив чисел [5, 12, 8, 130, 44]:
1. Відфільтруйте числа > 10
2. Подвойте кожне число через map
3. Знайдіть суму всіх чисел через reduce
4. Відсортуйте за спаданням
5. Створіть новий масив, де кожне число перетворено в рядок `"Число: X"`

### Завдання 3. Об'єкт користувача
Створіть об'єкт `user`:
1. Поля: name, age, email, skills (масив рядків)
2. Метод `introduce()`, який виводить "Привіт, я {name}, мені {age} років"
3. Метод `addSkill(skill)`, який додає навичку в масив
4. Виведіть всі ключі та значення об'єкта через Object.entries()

### Завдання 4. Функції
1. Напишіть функцію `isPalindrome(str)`, яка перевіряє, чи є рядок паліндромом
2. Напишіть функцію `fizzBuzz(n)`, яка виводить числа від 1 до n, але замість чисел кратних 3 — "Fizz", 5 — "Buzz", 3 і 5 — "FizzBuzz"
3. Напишіть стрілочну функцію `average(...nums)`, яка рахує середнє будь-якої кількості чисел

### Критерії прийому:
- Код запускається в консолі браузера без помилок
- Використано let/const (не var)
- Використано стрілочні функції
- Код відформатовано
