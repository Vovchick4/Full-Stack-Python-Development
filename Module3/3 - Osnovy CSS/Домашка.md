### Завдання 1
Створіть HTML сторінку та підключіть зовнішній CSS. Стилізуйте заголовки, абзаци, посилання.

### Завдання 2
Створіть картку товару: зображення, заголовок, ціна, кнопка. Стилізуйте через класи. Box model: padding, border, margin, border-radius, box-shadow.

### Завдання 3
Створіть навігацію (меню) з горизонтальним розташуванням. При наведенні — зміна кольору (hover). Active пункт має бути візуально виділений.
