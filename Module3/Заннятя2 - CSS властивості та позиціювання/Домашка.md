## Домашнє завдання: CSS властивості та позиціювання

### Завдання 1. Sticky навігація
Створіть сторінку з:
- Sticky header, який залишається зверху при скролі
- Боковою панеллю (sidebar) з position: sticky
- Кнопкою "Вгору" (fixed внизу справа), яка плавно з'являється при скролі

### Завдання 2. Картки з анімацією
Створіть 3 картки, які:
- При наведенні піднімаються вгору (transform + transition)
- Мають тінь, яка збільшується при hover
- З'являються з анімацією fadeIn при завантаженні
- Мають різну затримку анімації (animation-delay)

### Завдання 3. Модальне вікно
Створіть модальне вікно:
- Overlay на весь екран
- Вікно по центру з absolute/relative
- Кнопка закриття в правому верхньому куті
- Анімація появи (scale + opacity)

### Завдання 4 (⭐ Зірочка). Лоадер
Створіть CSS-анімацію для:
- Спінера (круг, що обертається)
- Скелетону (пульсуючі блоки для завантаження контенту)
- Progress bar, який заповнюється з анімацією

### Критерії прийому:
- Всі види позиціювання використано (relative, absolute, fixed, sticky)
- Анімації та переходи працюють
- Код не використовує JavaScript (крім появи модалки)
- Кросс-браузерна сумісність
