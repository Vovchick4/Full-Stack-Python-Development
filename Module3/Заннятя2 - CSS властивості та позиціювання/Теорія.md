## 1. Одиниці вимірювання

```css
/* Абсолютні */
.px { font-size: 16px; }     /* пікселі */
.pt { font-size: 12pt; }     /* пункти (1pt = 1/72 дюйма) */
.cm, .mm, .in { }            /* сантиметри, міліметри, дюйми */

/* Відносні */
.em { font-size: 1.5em; }    /* відносно розміру шрифту батька */
.rem { font-size: 1.5rem; }  /* відносно шрифту <html> (16px = 1rem) */
.vw { width: 50vw; }         /* 50% ширини вікна */
.vh { height: 100vh; }       /* 100% висоти вікна */
.vmin, vmax { }              /* мінімум/максимум з vw/vh */
% { width: 50%; }            /* відносно батька */
```

### em vs rem

```css
html { font-size: 16px; }

.parent { font-size: 2em; }  /* 32px */

.child-em { font-size: 2em; }  /* 64px (2 * 32 від батька) */
.child-rem { font-size: 2rem; } /* 32px (2 * 16 від html) */
```

## 2. Позиціювання (Position)

CSS position визначає, як елемент розташовується на сторінці.

```css
/* static — за замовчуванням, елемент у нормальному потоці */
.static { position: static; }

/* relative — зміщується відносно свого нормального місця */
.relative {
    position: relative;
    top: 20px;
    left: 30px;
    /* оригінальне місце залишається зарезервованим */
}

/* absolute — випадає з потоку, позиціонується відносно найближчого relative батька */
.absolute {
    position: absolute;
    top: 0;
    right: 0;
    /* якщо немає relative батька — відносно <body> */
}

/* fixed — прикріплено до вікна, не рухається при скролі */
.fixed {
    position: fixed;
    bottom: 20px;
    right: 20px;
    z-index: 1000;
}

/* sticky — relative, поки не доскролили, потім fixed */
.sticky {
    position: sticky;
    top: 0;
    background: white;
    z-index: 100;
}
```

### Приклад: модальне вікно

```css
.modal-overlay {
    position: fixed;
    top: 0;
    left: 0;
    width: 100vw;
    height: 100vh;
    background: rgba(0, 0, 0, 0.5);
    display: flex;
    justify-content: center;
    align-items: center;
    z-index: 999;
}

.modal {
    background: white;
    padding: 30px;
    border-radius: 12px;
    max-width: 500px;
    width: 90%;
    position: relative;
}

.modal-close {
    position: absolute;
    top: 10px;
    right: 10px;
    cursor: pointer;
}
```

## 3. Display

```css
.block { display: block; }            /* займає всю ширину, з нового рядка */
.inline { display: inline; }          /* у рядку, width/height ігноруються */
.inline-block { display: inline-block; } /* у рядку, але width/height працюють */
.none { display: none; }               /* прибирає елемент (невидимий + не займає місця) */
.flex { display: flex; }              /* flexbox */
.grid { display: grid; }              /* css grid */
```

### Різниця між display: none та visibility: hidden

```css
.hidden { visibility: hidden; }  /* невидимий, але місце займає */
.gone { display: none; }         /* повністю прибраний з потоку */
```

## 4. Overflow

```css
.visible { overflow: visible; }       /* видимий за межами (за замовч.) */
.hidden { overflow: hidden; }        /* обрізає */
.scroll { overflow: scroll; }        /* завжди показує скрол */
.auto { overflow: auto; }            /* скрол тільки при потребі */
.xy { overflow-x: hidden; overflow-y: auto; } /* окремо по осях */
```

## 5. Трансформації та переходи

```css
/* Трансформації */
.transform {
    transform: rotate(45deg);            /* поворот */
    transform: scale(1.5);               /* масштабування */
    transform: translate(50px, 100px);   /* зміщення */
    transform: skew(10deg);              /* нахил */
    transform: rotate(45deg) scale(1.2); /* комбінація */
    transform-origin: top left;          /* точка трансформації */
}

/* Переходи (анімація при зміні стану) */
.card {
    transition: all 0.3s ease;
    /* transition: property duration timing-function delay; */
    transition: background-color 0.3s, transform 0.2s;
    transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

.card:hover {
    transform: translateY(-5px);
    box-shadow: 0 8px 25px rgba(0,0,0,0.15);
}
```

## 6. Анімації (Keyframes)

```css
@keyframes fadeIn {
    from { opacity: 0; transform: translateY(20px); }
    to   { opacity: 1; transform: translateY(0); }
}

@keyframes spin {
    0%   { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
}

@keyframes pulse {
    0%, 100% { transform: scale(1); }
    50%      { transform: scale(1.05); }
}

.animated {
    animation: fadeIn 0.5s ease-in-out;
    /* animation: name duration timing-function delay iteration-count direction */
    animation: spin 1s linear infinite;
}

.loading-spinner {
    width: 40px;
    height: 40px;
    border: 4px solid #f3f3f3;
    border-top: 4px solid #3498db;
    border-radius: 50%;
    animation: spin 1s linear infinite;
}
```

## 7. Псевдокласи стану

```css
/* Посилання */
a:link { color: blue; }        /* не відвідане */
a:visited { color: purple; }   /* відвідане */
a:hover { color: red; }        /* наведення */
a:active { color: green; }     /* в момент кліку */

/* Форми */
input:focus { outline: 2px solid blue; }          /* фокус */
input:disabled { background: #eee; }              /* вимкнено */
input:checked { accent-color: green; }           /* чекбокс */
input:required { border-color: orange; }         /* обов'язкове */
input:valid { border-color: green; }             /* валідне */
input:invalid { border-color: red; }             /* невалідне */

/* Інші */
li:first-child { }            /* перший */
li:last-child { }             /* останній */
li:nth-child(2n) { }          /* парні */
li:nth-child(odd) { }         /* непарні */
li:not(.active) { }           /* всі, крім .active */
p:empty { display: none; }    /* порожні */
```

## 8. Практичний приклад: sticky header + modal

```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Сайт</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header class="header">
        <h1>Мій сайт</h1>
        <nav>
            <a href="#">Головна</a>
            <a href="#">Блог</a>
        </nav>
    </header>

    <main class="content">
        <p>Дуже довгий контент, щоб можна було скролити...</p>
        <button class="open-modal" onclick="showModal()">Відкрити</button>
    </main>

    <div class="modal-overlay" id="modal">
        <div class="modal">
            <span class="modal-close" onclick="hideModal()">&times;</span>
            <h2>Модальне вікно</h2>
            <p>Це вікно поверх контенту</p>
        </div>
    </div>

    <footer class="footer">Footer</footer>
</body>
</html>
```
