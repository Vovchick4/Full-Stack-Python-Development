## 1. Що таке фронтенд?

Фронтенд — це все, що бачить користувач у браузері. Він складається з трьох технологій:

| Технологія | Призначення |
|------------|-------------|
| **HTML** | Структура сторінки (скелет) |
| **CSS** | Стилі та оформлення (одяг) |
| **JavaScript** | Логіка та інтерактивність (м'язи) |

---

## 2. Основи HTML

HTML (HyperText Markup Language) — це мова розмітки, яка описує структуру веб-сторінки.

### Базова структура HTML-документа

```html
<!DOCTYPE html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя перша сторінка</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <header>
        <h1>Вітаємо на сайті!</h1>
        <nav>
            <ul>
                <li><a href="/">Головна</a></li>
                <li><a href="/about">Про нас</a></li>
                <li><a href="/contact">Контакти</a></li>
            </ul>
        </nav>
    </header>

    <main>
        <section>
            <h2>Останні новини</h2>
            <article>
                <h3>Новина 1</h3>
                <p>Текст новини...</p>
            </article>
        </section>

        <aside>
            <h3>Бокова панель</h3>
        </aside>
    </main>

    <footer>
        <p>&copy; 2026 Всі права захищені</p>
    </footer>
</body>
</html>
```

### Основні теги HTML

```html
<!-- Заголовки (h1-h6) -->
<h1>Найбільший заголовок</h1>
<h2>Підзаголовок</h2>
<h6>Найменший</h6>

<!-- Текст -->
<p>Абзац тексту</p>
<strong>Жирний текст</strong>
<em>Курсив</em>
<br> <!-- перенос рядка -->
<hr> <!-- горизонтальна лінія -->

<!-- Посилання -->
<a href="https://example.com" target="_blank">Зовнішнє посилання</a>
<a href="/about">Внутрішнє</a>
<a href="#section">Якір на секцію</a>

<!-- Зображення -->
<img src="images/photo.jpg" alt="Опис зображення" width="300">

<!-- Списки -->
<ul>                    <!-- невпорядкований -->
    <li>Пункт 1</li>
    <li>Пункт 2</li>
</ul>

<ol>                    <!-- впорядкований -->
    <li>Перший</li>
    <li>Другий</li>
</ol>

<!-- Таблиці -->
<table>
    <thead>
        <tr><th>Ім'я</th><th>Вік</th></tr>
    </thead>
    <tbody>
        <tr><td>Олена</td><td>25</td></tr>
        <tr><td>Іван</td><td>30</td></tr>
    </tbody>
</table>

<!-- Форми -->
<form action="/submit" method="post">
    <label for="name">Ім'я:</label>
    <input type="text" id="name" name="name" required>

    <label for="email">Email:</label>
    <input type="email" id="email" name="email">

    <label for="message">Повідомлення:</label>
    <textarea id="message" name="message"></textarea>

    <button type="submit">Відправити</button>
</form>

<!-- Семантичні теги HTML5 -->
<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>
```

## 3. Основи CSS

CSS (Cascading Style Sheets) — це мова стилів, яка визначає зовнішній вигляд HTML-елементів.

### Підключення CSS

```html
<!-- Зовнішній файл -->
<link rel="stylesheet" href="style.css">

<!-- Внутрішній (в <head>) -->
<style>
    body { font-family: Arial; }
</style>

<!-- Інлайн (в атрибуті) -->
<p style="color: red;">Червоний текст</p>
```

### Селектори

```css
/* Тег */
body { font-family: Arial, sans-serif; }

/* Клас */
.card { background: #fff; border: 1px solid #ddd; }

/* ID */
#header { background: #333; color: white; }

/* Вкладеність */
nav ul li { display: inline; }

/* Дочірні */
nav > ul > li { margin-right: 10px; }

/* Атрибут */
input[type="text"] { border: 1px solid blue; }

/* Псевдокласи */
a:hover { color: red; }
a:active { color: green; }
a:visited { color: purple; }
li:first-child { font-weight: bold; }
li:nth-child(2n) { background: #f5f5f5; }

/* Псевдоелементи */
p::first-letter { font-size: 2em; }
p::before { content: "→ "; }
p::after { content: " ←"; }

/* Комбінація */
.card h2 + p { margin-top: 0; }          /* сусідній */
.card h2 ~ p { color: gray; }            /* всі наступні */
```

### Каскадність та специфічність

```
Inline стилі    → 1000
#id             → 100
.клас           → 010
тег             → 001
```

```css
/* Який стиль переможе? */
#content p { color: red; }          /* 101 */
.card p { color: blue; }           /* 011 */
p { color: green; }                /* 001 */
```

## 4. Блокова модель (Box Model)

Кожен елемент — це прямокутник:

```
┌─────────────────────────────────┐
│          margin (зовні)         │
│  ┌───────────────────────────┐  │
│  │       border (рамка)      │  │
│  │  ┌─────────────────────┐  │  │
│  │  │    padding (всередині)│  │  │
│  │  │  ┌───────────────┐  │  │  │
│  │  │  │   content      │  │  │  │
│  │  │  └───────────────┘  │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

```css
.box {
    width: 300px;
    height: 200px;
    padding: 20px;           /* внутрішній відступ */
    border: 2px solid black; /* рамка */
    margin: 10px;            /* зовнішній відступ */
    box-sizing: border-box;  /* padding+border враховуються в width */
}
```

### box-sizing

```css
/* content-box (за замовчуванням): width = тільки контент */
/* border-box: width = контент + padding + border */

*, *::before, *::after {
    box-sizing: border-box;  /* стандарт для сучасних проектів */
}
```

## 5. Типові CSS властивості

```css
/* Текст */
body {
    font-family: 'Roboto', Arial, sans-serif;
    font-size: 16px;
    font-weight: 400;        /* normal, bold, 100-900 */
    line-height: 1.6;
    text-align: center;      /* left, right, justify */
    text-decoration: none;   /* underline, line-through */
    color: #333;
}

/* Фони */
.card {
    background-color: #f0f0f0;
    background-image: url('bg.jpg');
    background-size: cover;  /* contain, auto */
    background-position: center;
    background-repeat: no-repeat;
}

/* Списки */
nav ul {
    list-style: none;        /* прибирає маркери */
    list-style-type: square; /* disc, circle, decimal */
}

/* Межі та тіні */
.card {
    border: 1px solid #ddd;
    border-radius: 8px;      /* заокруглення */
    box-shadow: 2px 2px 10px rgba(0,0,0,0.1);
}

/* Колірні схеми */
color: red;                  /* за назвою */
color: #ff0000;              /* hex */
color: rgb(255, 0, 0);       /* rgb */
color: rgba(255, 0, 0, 0.5); /* rgba з прозорістю */
```

    <meta charset="UTF-8">
