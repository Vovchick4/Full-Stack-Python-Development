## Домашнє завдання: HTML і CSS

### Завдання 1. Структура HTML
Створіть HTML-сторінку "Мій блог":
1. Header з логотипом та навігацією (Головна, Статті, Про мене, Контакти)
2. Main з секціями: останні статті, популярні теги
3. Footer з копірайтом та посиланнями на соцмережі
4. Використайте семантичні теги HTML5

### Завдання 2. Таблиця
Створіть HTML-таблицю розкладу занять:
1. Колонки: Час, Понеділок, Вівторок, ..., П'ятниця
2. Об'єднайте комірки з однаковими предметами (rowspan/colspan)
3. Додайте заголовок таблиці

### Завдання 3. Стилізація
Додайте CSS до сторінки блогу:
1. Встановіть шрифт, кольори, фони
2. Стилізуйте навігацію (горизонтальне меню)
3. Додайте картки для статей з тінню та заокругленням
4. Зробіть footer прикріпленим до низу

### Завдання 4 (⭐ Зірочка). Адаптивність
Додайте медіа-запити (media queries) для:
- Телефонів (max-width: 480px) — одноколонковий макет
- Планшетів (max-width: 768px) — дві колонки

### Критерії прийому:
- Валідний HTML5 (перевірте через validator.w3.org)
- Семантичні теги використано правильно
- CSS підключено зовнішнім файлом
- Сторінка коректно відображається в браузері
