## 1. Змінні та типи даних

```javascript
// var — не використовуємо (застаріло)
// let — змінна (можна змінювати)
let name = 'Олена';
name = 'Марія';

// const — стала (не можна змінити)
const age = 25;
// age = 30; // Error!

// Типи даних
const str = 'текст';           // string
const num = 42;                // number
const float = 3.14;            // float
const bool = true;             // boolean
const nothing = null;          // null (навмисно пусто)
const undef = undefined;       // undefined (не визначено)
const big = 123n;              // bigint
const id = Symbol('id');       // symbol

// Перевірка типу
typeof 'hello';    // 'string'
typeof 42;         // 'number'
typeof true;       // 'boolean'
typeof null;       // 'object' (!)
```

## 2. Перетворення типів

```javascript
// Явне перетворення
String(123);        // '123'
Number('123');      // 123
Number('abc');      // NaN
Boolean(1);         // true
Boolean(0);         // false
Boolean('');        // false

// Неявне перетворення
'5' - 3;            // 2 (number)
'5' + 3;            // '53' (string)
5 + '3';            // '53'
+'123';             // 123 (унарний +)
!!'hello';          // true

// Falsy значення: false, 0, '', null, undefined, NaN
// All інші — truthy
```

## 3. Правила іменування змінних

```javascript
// Дозволено: літери, цифри, $, _
// Не можна: починати з цифри
// Чутливі до регістру: name !== Name
// camelCase — стандарт для JS

let userName = 'Олена';
let user_age = 25;       // snake_case — для Python
const MAX_COUNT = 100;    // UPPER_CASE — для констант

// Осмислені назви
let x = 10;              // погано
let userAge = 10;        // добре
let d = new Date();      // погано
let currentDate = new Date(); // добре
```

## 4. Оператори

```javascript
// Арифметичні
+  -  *  /  %  **
// % — остача від ділення
// ** — піднесення до степеня

// Порівняння
==    // несуворе (5 == '5' → true)
===   // суворе (5 === '5' → false)
!=    // несуворе нерівно
!==   // суворе нерівно
>  <  >=  <=

// Логічні
&&    // І (всі true)
||    // АБО (хоч одна true)
!     // НЕ
??    // nullish (null/undefined → запасне значення)

// Інкремент/Декремент
let i = 0;
i++;   // постфікс
++i;   // префікс
```

## 5. Умовні конструкції

```javascript
// if/else if/else
const age = 18;
if (age >= 18) {
    console.log('Дорослий');
} else if (age >= 12) {
    console.log('Підліток');
} else {
    console.log('Дитина');
}

// Тернарний оператор
const status = age >= 18 ? 'Дорослий' : 'Дитина';

// Switch
const day = 1;
switch (day) {
    case 1: console.log('Пн'); break;
    case 2: console.log('Вт'); break;
    default: console.log('Інший');
}
```
