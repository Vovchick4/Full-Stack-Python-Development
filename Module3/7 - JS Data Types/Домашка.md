### Завдання 1
Створіть змінні різних типів (string, number, boolean, null, undefined). Виведіть тип кожної через typeof.

### Завдання 2
Напишіть код, який перевіряє вік користувача: якщо < 12 — "Дитина", < 18 — "Підліток", < 60 — "Дорослий", >= 60 — "Пенсіонер". Використайте if/else.

### Завдання 3
Створіть калькулятор з тернарним оператором: змінна operation ('+'/'-'/'*'/''/), два числа. Порахуйте результат. При невідомій операції — "Невідома операція". (Без switch).
